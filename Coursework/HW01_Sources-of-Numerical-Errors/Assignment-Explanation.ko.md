## 3. 문제 1: 지수 함수의 매클로린 부분합

### 3.1 풀이 방법

`f_approx[k]`가 나타내는 부분합을 $`S_k`$라 하자. 부분합은 다음 점화 관계를 만족한다.

$$
S_k = \sum_{i=0}^{k} \frac{x^i}{i!} = S_{k-1} + \frac{x^k}{k!}
$$

따라서 각 칸은 바로 앞 칸에 새 항 하나를 더해 구한다. 이미 채워진 `f_approx[2] = f_approx[1] + x**2 / math.factorial(2)`가 이 형식을 따르므로, 빈칸도 같은 형식으로 $`k = 3, 4, 5`$의 항을 더한다. 테일러 급수와 근사의 차수는 [4장 강의 노트](../../Lecture-Notes/Ch04_Roundoff-and-Truncation-Errors/Concepts_Lecture.ko.md)의 8, 9절에서 다룬다.

### 3.2 작성한 코드

```python
f_approx[3] = f_approx[2] + x**3 / math.factorial(3)   # k=3: + x^3/3!
f_approx[4] = f_approx[3] + x**4 / math.factorial(4)   # k=4: + x^4/4!
f_approx[5] = f_approx[4] + x**5 / math.factorial(5)   # k=5: + x^5/5!
```

### 3.3 실행 결과와 검증

```text
 Terms         Approximation    True Rel Err (%)
--------------------------------------------------
     1     1.000000000000000       39.3469340287
     2     1.500000000000000        9.0204010431
     3     1.625000000000000        1.4387677967
     4     1.645833333333333        0.1751622556
     5     1.648437500000000        0.0172115630
     6     1.648697916666667        0.0014164937
```

참값은 $`e^{0.5} = 1.648721270700128`$이다. 결과는 다음 두 가지로 확인한다.

- **부분합의 값:** $`S_3 = 1.625 + 0.5^3/6 = 1.6458\overline{3}`$, $`S_4 = S_3 + 0.5^4/24 = 1.6484375`$, $`S_5 = S_4 + 0.5^5/120 = 1.648697916\ldots`$로, 손으로 더한 값과 출력이 일치한다.
- **나머지 항의 범위:** 6항을 남기면 절단 오차는 테일러 나머지 $`R_5 = \frac{e^{\xi}}{6!} (0.5)^6`$ $`(0 < \xi < 0.5)`$이다. $`e^{\xi}`$가 1과 $`e^{0.5}`$ 사이에 있으므로 $`2.170 \times 10^{-5} < R_5 < 3.578 \times 10^{-5}`$이고, 실제 오차 $`e^{0.5} - S_5 = 2.335 \times 10^{-5}`$는 이 범위 안에 있다.

항을 하나 더할 때마다 오차가 줄어드는 비율은 0.229, 0.160, 0.122, 0.098, 0.082로 점점 작아진다. 분모의 팩토리얼이 분자의 거듭제곱보다 빠르게 커지기 때문이다.

## 4. 문제 2: 중지 기준을 쓴 급수 계산

### 4.1 풀이 방법

함수는 `sol = 1.0`(0차 항)에서 시작하고 $`k = 1`$부터 반복하므로, 반복 $`k`$에서 더할 항은 $`x^k / k!`$이다. 빈칸 뒤의 코드는 직전 부분합 `sol_old`와 새 부분합 `sol`로 근사 백분율 상대 오차를 계산한다.

$$
\varepsilon_a = \frac{|S_k - S_{k-1}|}{|S_k|} \times 100 = \frac{x^k / k!}{S_k} \times 100
$$

즉 $`\varepsilon_a`$는 새로 더한 항이 부분합에서 차지하는 비율이며, 이 값이 `es`보다 작아지면 반복을 멈춘다. 근사 백분율 상대 오차와 스카보로 기준은 [4장 강의 노트](../../Lecture-Notes/Ch04_Roundoff-and-Truncation-Errors/Concepts_Lecture.ko.md)의 3, 4절에서 다룬다.

### 4.2 작성한 코드

```python
        sol = sol + x**k / math.factorial(k)
```

### 4.3 실행 결과와 검증

```text
Stopping criterion: 0.005 %

   k         Approximation           ea (%)
---------------------------------------------
   1     1.500000000000000    33.3333333333
   2     1.625000000000000     7.6923076923
   3     1.645833333333333     1.2658227848
   4     1.648437500000000     0.1579778831
   5     1.648697916666667     0.0157952930
   6     1.648719618055555     0.0013162571

Result : 1.6487196181
True   : 1.6487212707

```

출력은 노트북에 실린 기대 출력과 글자까지 같다. 중지 기준은 `scarborough(4)` $`= 0.5 \times 10^{2-4} = 0.005\%`$이다. $`k = 5`$에서는 $`\varepsilon_a = 0.0158\% > 0.005\%`$이므로 계속하고, $`k = 6`$에서 $`\varepsilon_a = 0.00132\% < 0.005\%`$가 되어 멈춘다. 이때 참 백분율 상대 오차는 $`|1.6487212707 - 1.6487196181| / 1.6487212707 \times 100 \approx 1.0 \times 10^{-4}\%`$로 중지 기준보다 작다. 결과와 참값은 유효 숫자 6자리로 반올림하면 모두 1.64872가 되어, 스카보로 기준이 보장한 4자리보다 많은 자리가 맞는다.

> **참고:** 출력의 `Terms  : 6`은 마지막으로 더한 항의 차수 $`k`$이다. 부분합에는 0차 항부터 6차 항까지 7개의 항이 들어 있으며, 결과 $`1.648719618\ldots`$는 문제 1의 $`S_5`$에 $`0.5^6 / 6! = 2.170 \times 10^{-5}`$을 더한 $`S_6`$이다.

## 5. 문제 3: 이차 방정식의 근과 재앙적 소거

### 5.1 풀이 방법

셀은 $`a = 1`$, $`b = -b_{\text{val}}`$, $`c = 1`$로 놓으므로 $`-b`$는 양수이다. 근의 공식의 두 근은 다음과 같다.

$$
x_1 = \frac{-b + \sqrt{b^2 - 4ac}}{2a}, \qquad x_2 = \frac{-b - \sqrt{b^2 - 4ac}}{2a}
$$

$`x_1`$의 분자는 양수 두 개의 덧셈이어서 소거가 일어나지 않는다. 반면 $`b^2 \gg 4ac`$이면 $`\sqrt{b^2 - 4ac} \approx |b|`$이므로 $`x_2`$의 분자는 거의 같은 두 수의 뺄셈이 되어 재앙적 소거가 일어난다. 안정한 형태는 근과 계수의 관계 $`x_1 x_2 = c/a`$에서 나온다.

$$
x_2 = \frac{c}{a x_1}
$$

정확하게 구한 $`x_1`$에 나눗셈 한 번만 더하므로 상대 오차가 커지지 않는다. 그래서 `x1_s`에는 덧셈 부호의 공식을, `x2_stab`에는 주석의 형태를 쓴다. 뺄셈 소거는 [4장 강의 노트](../../Lecture-Notes/Ch04_Roundoff-and-Truncation-Errors/Concepts_Lecture.ko.md)의 6.1절과 [4장 실습 노트](../../Lecture-Notes/Ch04_Roundoff-and-Truncation-Errors/Concepts_Lab.ko.md)의 3.5절에서 다룬다.

### 5.2 작성한 코드

```python
    x1_s = (-b_ + disc) / (2*a_)
    x2_s = (-b_ - disc) / (2*a_)  # standard formula
    x2_stab = c_ / (a_ * x1_s)   # stable formula: c / (a * x1)
```

### 5.3 실행 결과와 검증

```text
           b       x2 standard         x2 stable    rel err std (%)    rel err stable (%)
------------------------------------------------------------------------------------------
       1e+02      0.0100010002      0.0100010002       1.221123e-11          0.000000e+00
       1e+04      0.0001000000      0.0001000000       1.117663e-07          0.000000e+00
       1e+06      0.0000010000      0.0000010000       7.614492e-04          0.000000e+00
       1e+08      0.0000000075      0.0000000100       2.549419e+01          0.000000e+00
       1e+10      0.0000000000      0.0000000001       1.000000e+02          0.000000e+00
```

출력은 배포 노트북에 실린 출력과 같다. 결과는 다음과 같이 해석한다.

- **표준 공식의 오차 증가:** $`b`$가 100배 커질 때 상대 오차는 $`1.2 \times 10^{-11}\%`$에서 $`1.1 \times 10^{-7}\%`$, $`7.6 \times 10^{-4}\%`$로 대략 $`10^4`$배씩 커진다. $`\sqrt{b^2 - 4}`$를 반올림할 때 생기는 절대 오차는 $`|b|`$와 함께 커지는데, 구하려는 $`x_2 \approx 1/|b|`$는 오히려 작아지기 때문이다.
- **$`b = 10^{10}`$의 100% 오차:** $`b^2 = 10^{20}`$ 근처에서 배정밀도 수의 간격은 16384이므로 $`b^2 - 4`$는 $`b^2`$로 반올림된다. 그러면 `disc`가 $`|b|`$와 정확히 같아져 `x2_s`가 0이 되고, 상대 오차는 100%이다.
- **안정한 형태의 오차 0:** 기준값 `x2_ref = 1.0 / x1_s`는 $`a = c = 1`$일 때 `x2_stab = c_ / (a_ * x1_s)`와 같은 식이므로, 마지막 열이 정확히 0인 것은 정의상 당연하다. 안정한 형태가 정확한 근거는 이 열이 아니라 5.1절의 논리, 곧 `x1_s`에 소거가 없고 나눗셈이 상대 오차를 키우지 않는다는 점에 있다.

> **참고:** 이 셀은 $`b < 0`$이어서 덧셈 부호의 공식이 큰 근을 준다. $`b > 0`$이면 $`-b - \sqrt{b^2 - 4ac}`$ 쪽이 같은 부호의 덧셈이 되므로, 일반적으로는 $`-b`$와 같은 부호로 제곱근을 더한 근을 먼저 구한 뒤 다른 근을 $`c / (a x_1)`$로 구한다.

> **참고:** 과제 안내문 문제 3의 첫 예제 셀은 방정식 $`x^2 - 100000.0001x + 1 = 0`$의 참값을 $`x_1 = 100000.00000999990`$, $`x_2 = 0.000010000000100000`$으로 두지만, 이 방정식의 실제 근은 $`x_1 = 100000.00009000\ldots`$, $`x_2 = 9.999999991 \times 10^{-6}`$이다. 따라서 그 셀이 출력한 표준 공식 $`x_1`$의 오차 $`8.00 \times 10^{-5}`$는 잘못 적힌 참값에서 생긴 값이며, 실제 근과 비교하면 표준 공식의 $`x_1`$은 반올림 오차 수준으로 정확하다. 실제 근과 비교한 $`x_2`$의 오차는 표준 공식이 $`3.9 \times 10^{-12}`$, 안정한 형태가 $`10^{-20}`$ 이하이므로, 안정한 형태가 더 정확하다는 결론은 그대로이다.

## 6. 문제 4: 세 가지 유한 차분 공식

### 6.1 풀이 방법

앞 셀이 `fm` $`= f(x-h)`$, `fi` $`= f(x)`$, `fp` $`= f(x+h)`$를 계산해 두었으므로, 표 1의 세 공식은 이 값들의 차를 스텝 크기로 나눈 식이 된다. 전진 차분은 $`(f(x+h) - f(x))/h`$, 후진 차분은 $`(f(x) - f(x-h))/h`$, 중심 차분은 $`(f(x+h) - f(x-h))/(2h)`$이다. 세 공식의 유도와 오차의 차수는 [4장 강의 노트](../../Lecture-Notes/Ch04_Roundoff-and-Truncation-Errors/Concepts_Lecture.ko.md)의 10절에서 다룬다.

### 6.2 작성한 코드

```python
dfdx_forward  = (fp - fi) / h
dfdx_backward = (fi - fm) / h
dfdx_central  = (fp - fm) / (2*h)
```

### 6.3 실행 결과와 검증

```text
      Method    Estimate    True Rel Err (%)
---------------------------------------------
     Forward    -1.45000             58.9041
    Backward    -0.55000             39.7260
     Central    -1.00000              9.5890
        True    -0.91250
```

손으로 계산하면 $`(0.2 - 0.925)/0.5 = -1.45`$, $`(0.925 - 1.2)/0.5 = -0.55`$, $`(0.2 - 1.2)/1 = -1.0`$으로 출력과 같다. 오차는 테일러 전개로 정확히 설명된다. $`x = 0.5`$에서 $`f''(0.5) = -1.75`$, $`f'''(0.5) = -2.1`$, $`f^{(4)} = -2.4`$이므로 전진 차분의 오차는 다음과 같다.

$$
\frac{f''}{2}h + \frac{f'''}{6}h^2 + \frac{f^{(4)}}{24}h^3 = -0.4375 - 0.0875 - 0.0125 = -0.5375
$$

이는 $`-1.45 - (-0.9125)`$와 같다. 중심 차분에서는 짝수 차수 항이 상쇄되어 오차가 $`\frac{f'''}{6}h^2 = -0.0875`$만 남으며, $`f`$가 4차 다항식이라 5계도함수가 0이므로 이것이 정확한 오차이다. 또한 중심 차분 $`-1.0`$은 전진 차분과 후진 차분의 평균 $`(-1.45 - 0.55)/2`$과 같다. 두 차분의 1차 오차 항이 크기가 같고 부호가 반대여서 평균을 내면 상쇄되기 때문이다.

## 7. 문제 5: 스텝 크기에 따른 전진 차분과 중심 차분의 오차

### 7.1 풀이 방법

루프는 `H[i] = h`로 현재 스텝 크기를 기록한 뒤 빈칸을 거쳐 마지막에 `h /= 10`으로 스텝 크기를 줄인다. 따라서 빈칸은 현재의 `h`로 두 차분을 계산하고 참값과의 차의 절댓값을 저장한다. 노트북의 `step_size_analysis`가 중심 차분에 쓴 방식과 같으며, 전진 차분은 $`f(0.5+h)`$와 $`f(0.5)`$의 차를 $`h`$로 나눈다. 절단 오차와 반올림 오차의 균형, 최적 스텝 크기는 [4장 강의 노트](../../Lecture-Notes/Ch04_Roundoff-and-Truncation-Errors/Concepts_Lecture.ko.md)의 12절에서 다룬다.

### 7.2 작성한 코드

```python
    E_fwd[i] = abs(true_val - (f(0.5 + h) - f(0.5)) / h)
    E_cen[i] = abs(true_val - (f(0.5 + h) - f(0.5 - h)) / (2*h))
```

## 점검 문제

1. **출력의 Terms:** 문제 2의 출력에서 `Terms  : 6`은 몇 개의 항을 더했다는 뜻인가?

   <details>
   <summary>정답</summary>

   0차 항부터 6차 항까지 7개이다. 함수는 0차 항 `sol = 1.0`에서 시작하고 반복 변수 `k`는 마지막으로 더한 항의 차수이므로, `k = 6`에서 멈추면 항은 7개이다.

   </details>

2. **양수인 b:** 문제 3의 셀에서 $`b`$의 부호가 양수였다면 소거를 피하기 위해 `x1_s`를 어떻게 고쳐야 하는가?

   <details>
   <summary>정답</summary>

   $`b > 0`$이면 $`-b`$가 음수이므로 소거가 없는 근은 $`(-b - \sqrt{b^2 - 4ac})/(2a)`$이다. 이 근을 먼저 구하고 다른 근은 $`c/(a x_1)`$로 구한다. 일반적으로 $`-b`$와 같은 부호로 제곱근을 더한다.

   </details>

3. **중심 차분과 평균:** 문제 4에서 중심 차분이 전진 차분과 후진 차분의 평균과 같은 이유를 식으로 보여라.

   <details>
   <summary>정답</summary>

   $`\frac{1}{2}\left(\frac{f(x+h) - f(x)}{h} + \frac{f(x) - f(x-h)}{h}\right) = \frac{f(x+h) - f(x-h)}{2h}`$이다. $`f(x)`$가 상쇄되어 중심 차분 공식이 된다.

   </details>

4. **최적 스텝 크기의 차이:** 문제 5에서 전진 차분의 오차가 최소인 스텝 크기가 중심 차분보다 작은 이유를 설명하라.

   <details>
   <summary>정답</summary>

   전체 오차를 절단 오차와 반올림 오차의 합으로 보면 전진 차분은 $`Ch + \varepsilon/h`$, 중심 차분은 $`Ch^2 + \varepsilon/h`$ 꼴이다. 앞의 것은 $`h \sim \varepsilon^{1/2}`$, 뒤의 것은 $`h \sim \varepsilon^{1/3}`$에서 최소가 되며, $`\varepsilon \approx 2.2 \times 10^{-16}`$에서는 $`\varepsilon^{1/2}`$이 더 작다. 실제로 최소는 각각 $`10^{-8}`$과 $`10^{-6}`$에서 나타났다.

   </details>

5. **나머지 항의 범위:** 문제 1에서 $`S_5`$의 절단 오차가 $`2.17 \times 10^{-5}`$보다 크고 $`3.58 \times 10^{-5}`$보다 작아야 하는 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   테일러 나머지는 $`R_5 = e^{\xi} (0.5)^6 / 6!`$ $`(0 < \xi < 0.5)`$이고, $`1 < e^{\xi} < e^{0.5}`$이므로 $`(0.5)^6 / 720 = 2.17 \times 10^{-5}`$과 $`e^{0.5} (0.5)^6 / 720 = 3.58 \times 10^{-5}`$ 사이에 있다. 실제 오차는 $`2.34 \times 10^{-5}`$이다.

   </details>
