## 3. 문제 1: 고유값과 고유벡터의 계산

### 3.1 풀이 방법

`np.linalg.eig(A)`는 고유값 배열과 고유벡터 행렬의 두 값을 돌려주며, 고유벡터 행렬의 $`i`$번째 열이 $`i`$번째 고유값의 고유벡터이고 각 열의 2-노름은 1이다. 이 순서가 셀의 검증 코드 `A @ eigvecs[:, i] - eigvals[i] * eigvecs[:, i]`와 맞으므로 두 값을 그대로 풀어 받는다. 고유값과 특성 방정식은 [13장 강의 노트](../../Lecture-Notes/Ch13_Eigenvalues-Symmetric-Matrices/Concepts_Lecture.ko.md)에서 다룬다.

### 3.2 작성한 코드

```python
eigvals, eigvecs = np.linalg.eig(A)
```

### 3.3 실행 결과와 검증

```text
Eigenvalues:
  lambda_1 = 21.72915618
  lambda_2 = 13.18232626
  lambda_3 = 6.08851756

Eigenvectors (columns):
[[ 0.89819   0.427012  0.104481]
 [ 0.30972  -0.44601  -0.839732]
 [ 0.311976 -0.786598  0.532855]]

Verification  max|A v - lambda v|:
  lambda_1: 3.55e-15
  lambda_2: 7.11e-15
  lambda_3: 8.88e-16
```

고유값과 고유벡터는 배포 노트북의 출력과 같다. 잔차의 마지막 값은 배포 노트북의 `1.33e-15`와 조금 다른데, 둘 다 반올림 오차 수준이어서 실행 환경의 부동 소수점 연산 순서 차이로 볼 수 있다. 결과는 다음 세 가지로 확인한다.

- **잔차:** 세 고유쌍 모두 $`\max|A\mathbf{v} - \lambda\mathbf{v}|`$가 $`10^{-15}`$ 수준으로, 머신 엡실론에 행렬 원소의 크기를 곱한 정도이다.
- **대각합과 행렬식:** 이어지는 셀의 출력에서 $`\text{tr}(A) = 20 + 9 + 12 = 41`$과 고유값의 합 $`21.729 + 13.182 + 6.089 = 41.000`$이 같고, $`\det(A) = 1744`$와 고유값의 곱도 같다.
- **직교성:** $`A`$가 대칭이므로 고유벡터는 서로 직교하며, 이어지는 셀이 출력한 $`V^T V`$는 단위 행렬이다.

## 4. 문제 2: 거듭제곱법

### 4.1 풀이 방법

알고리즘의 2, 3단계를 그대로 옮긴다. $`i^* = \arg\max_i |y_i|`$는 `np.argmax(np.abs(y))`로 구하고, 고유값 추정은 그 위치의 성분 자체 `y[i*]`이다. 절댓값이 아니라 부호가 있는 성분을 쓰는 것이 중요하다. 지배 고유값이 음수이면 $`\mathbf{y} = A\mathbf{x}`$의 부호가 반복마다 바뀌는데, 부호 있는 성분으로 나누어야 $`\mathbf{x}`$의 부호가 고정되고 추정값이 음의 고유값으로 수렴한다. `x = y / lam`으로 나누면 가장 큰 성분이 1이 되어 $`\|\mathbf{x}\|_\infty = 1`$이 유지되고, 반복이 많아져도 오버플로가 생기지 않는다. 거듭제곱법은 [12장 실습 노트](../../Lecture-Notes/Ch12_Iterative-Methods/Concepts_Lab.ko.md)의 2절에서 다룬다.

### 4.2 작성한 코드

```python
        lam = y[np.argmax(np.abs(y))]
        x   = y / lam
```

### 4.3 실행 결과와 검증

```text
Converged in 51 iterations
Dominant eigenvalue (Power Method): 21.729156182199
True value (numpy)                : 21.729156182169
Absolute error                    : 3.02e-11

Theoretical convergence rate |λ₂/λ₁| = 0.606665
  -> error halves every 1.4 iterations
```

출력은 배포 노트북의 출력과 같다. 수렴 속도는 $`|\lambda_2/\lambda_1| = 13.1823/21.7292 = 0.6067`$이므로 오차는 반복마다 약 0.61배가 되고, $`\ln 2 / (-\ln 0.6067) = 1.39`$회마다 절반이 된다.

최종 오차 $`3.02 \times 10^{-11}`$은 중지 기준과도 맞아떨어진다. 오차가 $`e_k \approx C r^k`$ $`(r = 0.6067)`$로 줄면 연속한 추정값의 변화는 $`e_{k-1} - e_k = e_k (1/r - 1)`$이므로, 오차는 변화량의 $`r/(1-r) = 1.54`$배이다. 반복은 상대 변화가 $`10^{-12}`$보다 작아질 때, 곧 변화량이 $`21.73 \times 10^{-12}`$보다 작아질 때 멈추므로 오차는 약 $`1.54 \times 2.17 \times 10^{-11} = 3.35 \times 10^{-11}`$보다 작아야 하며, 실제 값 $`3.02 \times 10^{-11}`$은 이 범위 안에 있다. 이처럼 수렴이 느릴수록($`r`$이 1에 가까울수록) 변화량에 근거한 중지 기준은 실제 오차를 과소평가한다.

## 5. 문제 3: 역거듭제곱법과 편이 거듭제곱법

### 5.1 풀이 방법

$`B = A - \sigma I`$의 역행렬에 거듭제곱법을 적용하되 역행렬을 만들지 않는다. 반복마다 $`\mathbf{y} = B^{-1}\mathbf{x}`$ 대신 $`B\mathbf{y} = \mathbf{x}`$를 푸는데, $`B`$는 반복 내내 같으므로 반복 전에 `sc.linalg.lu_factor(B)`로 한 번 분해해 두고 반복마다 `sc.linalg.lu_solve(lu_obj, x)`로 전진 대입과 후진 대입만 한다. 분해는 $`O(n^3)`$, 대입은 $`O(n^2)`$이다.

정규화 인자 `mu`는 $`B^{-1}`$의 지배 고유값 $`1/(\lambda - \sigma)`$로 수렴하므로 원래 고유값은 다음과 같이 복원한다.

$$
\mu = \frac{1}{\lambda - \sigma} \quad\Longrightarrow\quad \lambda = \sigma + \frac{1}{\mu}
$$

역거듭제곱법과 편이 거듭제곱법은 [12장 실습 노트](../../Lecture-Notes/Ch12_Iterative-Methods/Concepts_Lab.ko.md)의 3절에서 다룬다.

### 5.2 작성한 코드

```python
    lu_obj = sc.linalg.lu_factor(B)
```

```python
        y   = sc.linalg.lu_solve(lu_obj, x)
        mu  = y[np.argmax(np.abs(y))]                # largest element of y  (= 1 / (lambda - sigma))
        x   = y / mu
        lam = sigma + 1.0 / mu
```

### 5.3 실행 결과와 검증

```text
All eigenvalues (numpy, ascending): [ 6.088518 13.182326 21.729156]

Method                                Found lambda   True lambda       Error   Iters
------------------------------------------------------------------------------------
Power Method   (dominant)              21.72915618   21.72915618    3.02e-11      51
sigma=0        (smallest)               6.08851756    6.08851756    2.68e-12      38
sigma=10       (middle)                13.18232626   13.18232626    5.06e-12     127
sigma=24       (largest)               21.72915618   21.72915618    1.34e-12      18
```

출력은 배포 노트북의 출력과 같으며, 세 편이가 각각 $`\sigma`$에 가장 가까운 고유값을 찾았다. 반복 횟수의 차이는 $`B^{-1}`$에서의 수렴 속도로 설명된다. $`B^{-1}`$의 고유값은 $`1/(\lambda_i - \sigma)`$이므로 수렴 속도는 $`\sigma`$에 가장 가까운 고유값까지의 거리를 두 번째로 가까운 고유값까지의 거리로 나눈 값이다.

| 편이 | 가장 가까운 고유값까지의 거리 | 두 번째로 가까운 고유값까지의 거리 | 수렴 속도 | 반복 횟수 |
|:-----|:-----|:-----|:-----|:-----|
| $`\sigma = 0`$ | 6.0885 | 13.1823 | 0.462 | 38 |
| $`\sigma = 10`$ | 3.1823 | 3.9115 | 0.814 | 127 |
| $`\sigma = 24`$ | 2.2708 | 10.8177 | 0.210 | 18 |

*표 2. 편이에 따른 수렴 속도와 반복 횟수*

$`\sigma = 10`$은 두 고유값 6.09와 13.18 사이에 있어 두 거리가 비슷하므로 수렴이 느리고, $`\sigma = 24`$는 21.73에 가깝고 13.18과는 멀어 거듭제곱법(수렴 속도 0.607, 51회)보다도 빠르다. 편이를 목표 고유값에 가깝게 고를수록 수렴이 빨라진다.

## 6. 문제 4: 진동계의 고유 주파수

### 6.1 풀이 방법

`sc.linalg.eigh(K_vib, M_vib)`가 돌려준 `omega_sq`는 $`\lambda = \omega^2`$이므로 각진동수는 제곱근이고, 주파수는 각진동수를 한 바퀴의 각도 $`2\pi`$로 나눈 값이다.

$$
\omega_n = \sqrt{\lambda}, \qquad f = \frac{\omega_n}{2\pi}, \qquad T = \frac{1}{f}
$$

`omega_sq`는 배열이므로 `np.sqrt`로 세 모드를 한 번에 계산한다. 일반화 고유값 문제와 고유 주파수는 [13장 실습 노트](../../Lecture-Notes/Ch13_Eigenvalues-Symmetric-Matrices/Concepts_Lab.ko.md)의 2절에서 다룬다.

### 6.2 작성한 코드

```python
omega_n = np.sqrt(omega_sq)
freq_hz = omega_n / (2 * np.pi)
```


출력은 배포 노트북의 출력과 같다. 1차 모드로 확인하면 $`\sqrt{9.0470} = 3.0078`$ rad/s, $`3.0078 / (2\pi) = 0.4787`$ Hz, $`1/0.4787 = 2.0889`$ s이다. 잔차는 $`10^{-14}`$ 수준이며, `eigh`가 돌려준 모드 형상은 $`M`$에 대해 정규화되어 $`V^T M V = I`$를 만족한다. 고유값이 양수이므로 제곱근이 실수이고, 이는 $`K`$와 $`M`$이 대칭 양의 정부호이기 때문이다.

## 7. 문제 5: ODE 시스템의 모드 상수

### 7.1 풀이 방법

$`t = 0`$에서 해는 $`\mathbf{y}(0) = \sum_i c_i \mathbf{v}_i = V\mathbf{c}`$이므로 모드 상수는 선형 시스템 $`V\mathbf{c} = \mathbf{y}_0`$의 해이다. $`V^{-1}`$을 만들어 곱하지 않고 `np.linalg.solve`로 직접 푸는 편이 계산량이 적고 반올림 오차도 작다. 이는 [11장 실습 노트](../../Lecture-Notes/Ch11_Matrix-Inverse-and-Condition/Concepts_Lab.ko.md)의 1.2절에서 다룬, 역행렬 대신 직접 풀라는 황금 규칙과 같다. ODE 시스템의 안정성은 [13장 실습 노트](../../Lecture-Notes/Ch13_Eigenvalues-Symmetric-Matrices/Concepts_Lab.ko.md)의 3절과 [13장 강의 노트](../../Lecture-Notes/Ch13_Eigenvalues-Symmetric-Matrices/Concepts_Lecture.ko.md)에서 다룬다.

### 7.2 작성한 코드

```python
c_ode = np.linalg.solve(V_ode, y0)
```

### 7.3 실행 결과와 검증

```text
Eigenvalues:
  lambda_1 = -3.989933   -> mode decays
  lambda_2 = -302.010067   -> mode decays
System is STABLE

Modal constants: c1 = 53.6413,  c2 = 82.8879

Time constants:  tau_1 = 1/|lambda_1| = 0.2506 s  (slow mode)
                 tau_2 = 1/|lambda_2| = 0.003311 s  (fast mode)
Stiffness ratio  |lambda_2 / lambda_1| = 75.7
```

출력은 배포 노트북의 출력과 같다. 결과는 다음과 같이 확인한다.

- **고유값:** 대각합 $`-306`$과 행렬식 $`(-5)(-301) - 3 \cdot 100 = 1205`$에서 특성 방정식은 $`\lambda^2 + 306\lambda + 1205 = 0`$이고, $`\lambda = (-306 \pm \sqrt{88816})/2 = -3.9899, -302.0101`$이다. 두 실수부가 모두 음수이므로 표 1에 따라 시스템은 점근적으로 안정하다.
- **모드 상수:** `np.linalg.eig`가 돌려준 고유벡터 $`\mathbf{v}_1 = (0.9477, 0.3191)`$, $`\mathbf{v}_2 = (-0.0101, 0.99995)`$로 $`V\mathbf{c}`$를 계산하면 $`0.9477 \times 53.6413 - 0.0101 \times 82.8879 = 50.0`$, $`0.3191 \times 53.6413 + 0.99995 \times 82.8879 = 100.0`$으로 $`\mathbf{y}_0`$이 복원된다.
- **시간 상수와 강성비:** $`1/3.9899 = 0.2506`$ s, $`1/302.01 = 0.003311`$ s이고, 두 시간 상수의 비 75.7은 빠른 모드와 느린 모드의 시간 규모가 크게 다른 강성 시스템임을 보여 준다.

> **참고:** 고유벡터는 크기와 부호를 정할 자유가 있으므로 모드 상수 $`c_i`$의 값은 고유벡터의 정규화에 따라 달라진다. `np.linalg.eig`는 2-노름이 1인 고유벡터를 돌려주며, 다른 정규화를 쓰면 $`c_i`$는 바뀌지만 곱 $`c_i \mathbf{v}_i`$와 해 $`\mathbf{y}(t)`$는 바뀌지 않는다.

| 거듭제곱법 | 절댓값이 가장 큰 성분을 부호와 함께 고유값 추정으로 쓰고 그 값으로 나누어 정규화하며, 오차는 반복마다 약 $`\vert\lambda_2/\lambda_1\vert`$배로 준다. |
| 중지 기준과 실제 오차 | 오차가 비율 $`r`$로 줄 때 실제 오차는 연속한 추정값의 변화량의 약 $`r/(1-r)`$배이다. |

| 모드 상수와 안정성 | 모드 상수는 $`V\mathbf{c} = \mathbf{y}_0`$을 풀어 구하고, 모든 고유값의 실수부가 음수이면 시스템은 점근적으로 안정하다. |

## 점검 문제

1. **부호 있는 고유값 추정:** 문제 2에서 `lam = np.max(np.abs(y))`로 쓰면 지배 고유값이 음수인 행렬에서 어떤 일이 생기는가?

   <details>
   <summary>정답</summary>

   추정값이 항상 양수가 되어 음의 고유값을 얻을 수 없다. 또한 $`\mathbf{y} = A\mathbf{x}`$의 부호가 반복마다 바뀌는데 양수로만 나누므로 $`\mathbf{x}`$도 부호가 번갈아 바뀌어 수렴하지 않는다. 부호 있는 성분 `y[np.argmax(np.abs(y))]`로 나누어야 $`\mathbf{x}`$가 고정되고 추정값이 음의 고유값으로 수렴한다.

   </details>

2. **LU 분해의 위치:** 문제 3에서 `lu_factor`를 반복문 안에서 호출해도 결과는 같다. 그래도 반복문 밖에 두는 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   $`B = A - \sigma I`$는 반복 내내 바뀌지 않으므로 분해를 한 번만 하면 된다. 분해는 $`O(n^3)`$, 분해를 이용한 대입은 $`O(n^2)`$이므로, 반복문 밖에서 한 번 분해하면 반복마다 $`O(n^2)`$만 들고, 안에서 매번 분해하면 반복마다 $`O(n^3)`$이 든다.

   </details>

3. **편이의 선택:** 문제 3의 행렬에서 중간 고유값 13.18을 $`\sigma = 10`$보다 빨리 찾으려면 편이를 어떻게 정해야 하는가? $`\sigma = 13`$일 때의 수렴 속도를 계산하라.

   <details>
   <summary>정답</summary>

   13.18에 더 가깝게 두면 된다. $`\sigma = 13`$이면 가장 가까운 고유값 13.18까지의 거리는 0.18, 두 번째로 가까운 6.09까지의 거리는 6.91이므로 수렴 속도는 $`0.18/6.91 \approx 0.026`$으로, $`\sigma = 10`$의 0.814보다 훨씬 작아 몇 번의 반복으로 수렴한다.

   </details>

4. **주기의 계산:** 문제 4의 2차 모드에서 $`\omega^2 = 32.3636`$일 때 주파수와 주기를 손으로 구하라.

   <details>
   <summary>정답</summary>

   $`\omega = \sqrt{32.3636} = 5.6889`$ rad/s, $`f = 5.6889/(2\pi) = 0.9054`$ Hz, $`T = 1/0.9054 = 1.1045`$ s이다.

   </details>

5. **안정성 판정:** 문제 5의 행렬에서 $`a_{22} = -301`$을 $`+301`$로 바꾸면 시스템은 안정한가?

   <details>
   <summary>정답</summary>

   행렬식이 $`(-5)(301) - 3 \cdot 100 = -1805 < 0`$이 되어 두 고유값의 곱이 음수이다. 따라서 고유값 하나는 양수이고, 그 모드가 지수적으로 커지므로 시스템은 불안정하다.

   </details>
