## 3. 문제: 단측 파워 스펙트럼

### 3.1 풀이 방법

핵심은 두 배열의 인덱스를 맞추는 것이다. `compute_dft`는 `freq = np.arange(1, N) / T_total`로 만들므로, `freq`의 $`i`$번째 원소는 $`k = i + 1`$의 주파수 $`(i+1)/T_{\text{total}}`$이다. 반면 `Y`의 $`k`$번째 원소는 그대로 $`Y_k`$이다. 단측 스펙트럼에 필요한 $`k = 1, \ldots, n_2`$($`n_2`$ = `N // 2`)는 두 배열에서 다음 위치에 있다.

| 필요한 값 | `freq`에서의 위치 | `Y`에서의 위치 |
|:-----|:-----|:-----|
| $`k = 1`$ ($`\Delta f`$) | `freq[0]` | `Y[1]` |
| $`k = n_2`$ (짝수 $`N`$이면 Nyquist 주파수) | `freq[n2 - 1]` | `Y[n2]` |
| 전체 | `freq[:n2]` | `Y[1:n2+1]` |

*표 2. 단측 스펙트럼에 필요한 원소의 위치*

따라서 `fP`는 `freq[:n2]`이고, `Pyy`는 `Y[1:n2+1]`의 절댓값을 제곱한 것이다. `np.abs`는 복소수에 대해 크기 $`|Y_k| = \sqrt{\mathrm{Re}(Y_k)^2 + \mathrm{Im}(Y_k)^2}`$를 돌려준다. 직류 성분 $`Y_0`$과 거울상 절반 $`Y_{N/2+1}, \ldots, Y_{N-1}`$은 제외된다. DFT와 파워 스펙트럼의 정의는 [16장 강의 노트](../../Lecture-Notes/Ch16_Fourier-Analysis/Concepts_Lecture.ko.md)의 14, 17절에서 다룬다.

### 3.2 작성한 코드

```python
    fP  = freq[:n2]            #frequencies from delta_f to Nyquist
    Pyy = np.abs(Y[1:n2+1])**2 #power at each positive frequency
```

### 3.3 실행 결과와 검증

예제 16.3의 신호 $`f(t) = 5 + \cos(2\pi \cdot 12.5\, t) + \sin(2\pi \cdot 18.75\, t)`$를 $`N = 8`$, $`\Delta t = 0.02`$ s로 표본 추출한 결과이다.

```text
=== One-Sided Power Spectrum (Ex. 16.3) ===
   Freq [Hz]    Power |Yk|^2
------------------------------
      6.2500      0.00000000
     12.5000      0.25000000  <-- peak
     18.7500      0.25000000  <-- peak
     25.0000      0.00000000

Both signal frequencies are clearly identified as peaks.
```

출력은 배포 노트북에 실린 출력과 같으며, 다음과 같이 확인된다.

- **주파수:** $`T_{\text{total}} = 8 \times 0.02 = 0.16`$ s이므로 $`\Delta f = 6.25`$ Hz이고, $`n_2 = 4`$개의 주파수는 6.25, 12.5, 18.75, 25 Hz이다. 마지막 25 Hz는 $`f_s / 2 = 50 / 2`$로 Nyquist 주파수와 같다.
- **파워:** DFT 출력에서 $`Y_2 = 0.5`$, $`Y_3 = -0.5i`$이므로 $`|Y_2|^2 = |Y_3|^2 = 0.25`$이고, 나머지는 0이다. 두 피크가 신호의 두 주파수와 정확히 일치한다.
- **진폭과 파워의 관계:** 진폭이 $`A`$인 정현파는 양의 주파수 $`Y_k`$와 거울상 $`Y_{N-k}`$에 크기 $`A/2`$로 나뉘어 나타나므로, 이 노트북의 정의 $`P_k = |Y_k|^2`$에서 파워는 $`A^2/4`$이다. 두 성분의 진폭이 모두 1이므로 0.25이다.
- **Parseval 관계:** 모든 $`k`$에 대한 $`|Y_k|^2`$의 합은 $`25 + 4 \times 0.25 = 26`$이며, 이는 표본의 제곱 평균 $`\frac{1}{N}\sum y_j^2 = 26`$과 같다. 단측 스펙트럼의 합 0.5는 직류 성분을 뺀 파워 1의 절반이고, 나머지 절반은 거울상에 있다.

### 3.4 뒤의 셀에서 쓰인 결과

Exercise 4.1은 예제 16.1의 10개 점($`T = 1.5`$ s, $`\Delta t = 0.15`$ s)에 같은 함수를 적용한다.

```text
=== Power Spectrum for Example 16.1 ===
   Freq [Hz]    Power |Yk|^2
------------------------------
      0.6667        0.250047  <-- peak
      1.3333        0.000000
      2.0000        0.000000
      2.6667        0.000000
      3.3333        0.000000

Dominant frequency from spectrum : 0.6667 Hz
Expected (1/T = w0/(2*pi))       : 0.6667 Hz
Match? YES
```

피크의 주파수는 $`1/T = 0.6667`$ Hz이고, 파워 0.250047은 노트북 2절의 1차 Fourier 급수에서 구한 합성 진폭 $`C_1 = 1.0001`$로 계산한 $`C_1^2/4`$와 같다. 한 주기를 등간격으로 표본 추출하면 $`Y_1 = (A_1 - iB_1)/2`$이므로 $`|Y_1|^2 = (A_1^2 + B_1^2)/4`$가 성립하기 때문이다. $`N = 10`$이므로 $`n_2 = 5`$이고, 마지막 3.3333 Hz는 $`f_s / 2 = (1/0.15)/2`$로 Nyquist 주파수이다.

노트북 6절의 진동 분석은 $`f_s = 500`$ Hz, $`N = 512`$의 가속도 신호에 이 함수를 적용하고, 스펙트럼의 앞쪽 절반(125 Hz 이하)에서 가장 큰 파워의 주파수를 찾는다.

```text
Dominant frequency: 25.4 Hz  ->  1523 RPM
```

신호의 회전 성분은 25 Hz인데 결과는 25.4 Hz이다. 주파수 분해능이 $`\Delta f = 500/512 = 0.977`$ Hz여서 25 Hz는 이웃한 두 주파수 24.41 Hz와 25.39 Hz 사이에 놓이기 때문이다. 같은 계산을 다시 하면 두 주파수의 파워는 각각 0.250과 0.557로, 25 Hz 성분의 파워가 이웃 주파수에 나뉘어 나타나며, 더 큰 25.39 Hz가 선택된다.

> **참고:** 노트북 5절의 잡음 신호 셀은 $`t \in [0, 2\pi)`$에서 64개 표본을 쓰므로 `freq`의 단위는 단위 시간당 주기 수이다. 그래서 신호 $`\cos(10t) + \sin(3t)`$의 두 피크는 `fP`에서 $`3/(2\pi) = 0.477`$과 $`10/(2\pi) = 1.592`$에 나타난다. 그림의 축 이름(cycles per 2pi)과 출력 문장이 말하는 3과 10은 이 값이 아니라 DFT 인덱스 $`k`$이다.

## 요약

| 개념 | 핵심 요약 |
|:-----|:-----|
| 단측 파워 스펙트럼 | $`k = 1, \ldots, N/2`$의 주파수와 파워 $`P_k = \vert Y_k \vert^2`$만 남기며, 직류 성분과 거울상 절반은 제외한다. |
| 인덱스 대응 | `freq`는 $`k = 1`$부터 시작하므로 `fP = freq[:n2]`이고, `Y`는 $`k = 0`$부터 시작하므로 `Pyy`는 `Y[1:n2+1]`에서 구한다. |
| 진폭과 파워 | 진폭 $`A`$인 정현파는 $`Y_k`$와 $`Y_{N-k}`$에 $`A/2`$씩 나타나므로 이 정의에서 파워는 $`A^2/4`$이다. |
| 주파수 분해능 | $`\Delta f = 1/(N \Delta t)`$이며, 신호 주파수가 이 간격의 정수배가 아니면 파워가 이웃 주파수에 나뉘어 피크의 위치가 어긋난다. |
| Nyquist 주파수 | 짝수 $`N`$에서 단측 스펙트럼의 마지막 주파수는 $`f_s/2`$이며, 이보다 높은 성분은 표본 추출에서 구별할 수 없다. |

## 점검 문제

1. **원소의 개수:** 예제 16.3($`N = 8`$, $`\Delta t = 0.02`$ s)에서 `fP`의 원소는 몇 개이고 각각 몇 Hz인가?

   <details>
   <summary>정답</summary>

   $`n_2 = 8 // 2 = 4`$개이며, $`\Delta f = 1/0.16 = 6.25`$ Hz의 배수인 6.25, 12.5, 18.75, 25 Hz이다. 25 Hz는 Nyquist 주파수이다.

   </details>

2. **한 칸 어긋난 인덱스:** `fP = freq[1:n2+1]`로 잘못 쓰면 예제 16.3의 출력은 어떻게 달라지는가?

   <details>
   <summary>정답</summary>

   주파수가 한 칸씩 밀려 12.5, 18.75, 25, 31.25 Hz가 되므로, 실제로는 12.5 Hz와 18.75 Hz에 있는 두 피크가 18.75 Hz와 25 Hz에 있는 것처럼 출력된다. 파워 값은 그대로이고 주파수 이름표만 $`\Delta f`$만큼 어긋난다.

   </details>

3. **파워 0.25:** 예제 16.3의 두 성분은 진폭이 1인데 파워가 1이 아니라 0.25인 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   실수 정현파는 양의 주파수와 음의 주파수에 같은 크기로 나뉘므로, 정규화한 DFT에서 $`Y_k`$와 거울상 $`Y_{N-k}`$의 크기가 각각 $`A/2 = 0.5`$이다. 노트북은 단측 파워를 $`|Y_k|^2`$으로 정의하고 2배를 하지 않으므로 $`0.5^2 = 0.25`$이다.

   </details>

4. **25.4 Hz:** 진동 분석에서 회전 주파수가 25 Hz인데 25.4 Hz로 나온 이유를 설명하라.

   <details>
   <summary>정답</summary>

   $`N = 512`$, $`f_s = 500`$ Hz이므로 주파수 분해능은 $`500/512 = 0.977`$ Hz이고, 스펙트럼의 주파수는 그 정수배이다. 25 Hz는 24.41 Hz와 25.39 Hz 사이에 놓여 파워가 두 주파수에 나뉘며, 파워가 더 큰 25.39 Hz가 출력된다.

   </details>
