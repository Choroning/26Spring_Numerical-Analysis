## 3. 문제: 중심 차분 함수

### 3.1 풀이 방법

점 $`x`$의 양쪽으로 $`h`$만큼 떨어진 두 점에서 테일러 전개를 쓰면 다음과 같다.

$$
f(x \pm h) = f(x) \pm h f'(x) + \frac{h^2}{2} f''(x) \pm \frac{h^3}{6} f'''(x) + \cdots
$$

두 식을 빼면 짝수 차수 항이 상쇄되고 홀수 차수 항만 두 배로 남는다.

$$
f(x+h) - f(x-h) = 2h f'(x) + \frac{h^3}{3} f'''(x) + \cdots
$$

양변을 $`2h`$로 나누면 $`f'(x) \approx \frac{f(x+h) - f(x-h)}{2h}`$이고, 남는 오차의 주도 항은 $`\frac{h^2}{6} f'''(x)`$이다. 따라서 빈칸은 `func(x + h)`와 `func(x - h)`의 차를 `2 * h`로 나눈 값이다. 두 점 사이의 거리가 $`2h`$이므로 분모가 $`h`$가 아니라 $`2h`$라는 점에 주의해야 한다. 중심 차분의 유도는 [21장 강의 노트](../../Lecture-Notes/Ch21_Numerical-Differentiation/Concepts_Lecture.ko.md)의 2.3절에서 다룬다.

### 3.2 작성한 코드

```python
    cdiff = (func(x + h) - func(x - h)) / (2 * h)
```

### 3.3 실행 결과와 검증


출력은 배포 노트북에 실린 출력과 같다. 결과는 다음 세 가지로 확인한다.

**손 계산.** $`h = 0.5`$이면 $`f(1.0) = 0.1 - 0.2 + 3 + 2 - 1 + 0.5 = 4.4`$, $`f(0) = 0.5`$이므로 중심 차분은 $`(4.4 - 0.5)/1 = 3.9`$이다. 또한 $`f(0.5) = 0.865625`$에서 전진 차분은 $`(4.4 - 0.865625)/0.5 = 7.06875`$, 후진 차분은 $`(0.865625 - 0.5)/0.5 = 0.73125`$이고, 두 값의 평균 $`(7.06875 + 0.73125)/2 = 3.9`$가 중심 차분과 같다. 이 관계는 표의 모든 행에서 성립한다.

**오차의 정확한 구조.** 기준 함수는 5차 다항식이므로 $`f^{(5)} = 12`$로 상수이고 그보다 높은 도함수는 0이다. 전진 차분을 $`D_{\text{F}}(h)`$, 중심 차분을 노트북 3.2절의 기호대로 $`D(h)`$라 하자. 테일러 전개를 끝까지 쓰면 $`x_0 = 0.5`$에서 각 근사값과 참값의 차는 다음과 같다. 여기서 $`f''(0.5) = 12.65`$, $`f'''(0.5) = 17.1`$, $`f^{(4)}(0.5) = 1.2`$이다.

$$
D_{\text{F}}(h) - f'(x_0) = \frac{f''}{2}h + \frac{f'''}{6}h^2 + \frac{f^{(4)}}{24}h^3 + \frac{f^{(5)}}{120}h^4 = 6.325h + 2.85h^2 + 0.05h^3 + 0.1h^4
$$

$$
D(h) - f'(x_0) = \frac{f'''}{6}h^2 + \frac{f^{(5)}}{120}h^4 = 2.85h^2 + 0.1h^4
$$

후진 차분은 전진 차분에서 홀수 차수 항의 부호만 바뀐 $`-6.325h + 2.85h^2 - 0.05h^3 + 0.1h^4`$이다. 부호까지 포함한 오차는 다음과 같다.

| $`h`$ | 전진 차분의 오차 | 후진 차분의 오차 | 중심 차분의 오차 | $`2.85h^2 + 0.1h^4`$ |
|:-----|:-----|:-----|:-----|:-----|
| 0.5 | 3.887500e+00 | -2.450000e+00 | 7.187500e-01 | 7.187500e-01 |
| 0.25 | 1.760547e+00 | -1.403516e+00 | 1.785156e-01 | 1.785156e-01 |
| 0.1 | 6.610600e-01 | -6.040400e-01 | 2.851000e-02 | 2.851000e-02 |
| 0.05 | 3.233819e-01 | -3.091306e-01 | 7.125625e-03 | 7.125625e-03 |
| 0.01 | 6.353505e-02 | -6.296505e-02 | 2.850010e-04 | 2.850010e-04 |
| 0.001 | 6.327850e-03 | -6.322150e-03 | 2.850000e-06 | 2.850000e-06 |

*표 2. 스텝 크기에 따른 세 차분의 부호 있는 오차와 중심 차분의 오차식*

중심 차분의 오차는 모든 행에서 $`2.85h^2 + 0.1h^4`$과 일치한다. 중심 차분의 값이 참값보다 큰 것도 $`f'''(0.5) > 0`$이기 때문이다.

**오차의 수렴 비율.** $`h`$를 0.5에서 0.25로 절반으로 줄이면 중심 차분의 오차는 4.03배, 전진 차분은 2.21배 줄고, 0.1에서 0.05로 줄이면 각각 4.001배와 2.04배 준다. $`h`$를 0.01에서 0.001로 10분의 1로 줄이면 중심 차분의 오차는 100배, 전진 차분은 10.04배 준다. $`h`$가 작을수록 비율이 $`O(h^2)`$의 4와 100, $`O(h)`$의 2와 10에 가까워지는데, 높은 차수 항의 비중이 줄기 때문이다. 노트북의 수렴 그래프 셀이 $`10^{-4} < h \le 10^{-1}`$의 오차로 구한 수렴 차수도 전진 차분 1.00, 중심 차분 2.00이다.

### 3.4 뒤의 셀에서 쓰인 결과

노트북 3.2절의 함수 `richardson_extrap`은 `central_diff`로 $`D(h)`$와 $`D(h/2)`$를 구한 뒤 $`\frac{4D(h/2) - D(h)}{3}`$으로 결합한다. 완성한 노트북의 출력은 다음과 같다.

```text
Derivative estimates at x0=0.5  (exact = 3.1812500000)

       h    Central O(h^2)         err       5-pt O(h^4)         err   Richardson O(h^4)         err
---------------------------------------------------------------------------------------------------------
  0.5000      3.9000000000    7.19e-01      3.1562500000    2.50e-02        3.1796875000    1.56e-03
  0.2500      3.3597656250    1.79e-01      3.1796875000    1.56e-03        3.1811523438    9.77e-05
  0.1000      3.2097600000    2.85e-02      3.1812100000    4.00e-05        3.1812475000    2.50e-06
  0.0500      3.1883756250    7.13e-03      3.1812475000    2.50e-06        3.1812498438    1.56e-07
  0.0250      3.1830312891    1.78e-03      3.1812498438    1.56e-07        3.1812499902    9.77e-09
  0.0100      3.1815350010    2.85e-04      3.1812499960    4.00e-09        3.1812499997    2.50e-10
```

- **외삽의 오차:** 3.3절의 오차식 $`D(h) - f' = 2.85h^2 + 0.1h^4`$을 넣으면 $`\frac{4D(h/2) - D(h)}{3} - f' = -0.025h^4`$이다. $`h = 0.5`$에서 $`-0.025 \times 0.0625 = -1.5625 \times 10^{-3}`$, $`h = 0.1`$에서 $`-2.5 \times 10^{-6}`$으로 표의 오차와 같다. $`h^2`$ 항이 정확히 제거되어 오차가 $`O(h^4)`$가 된다.
- **5점 중심 차분과의 일치:** 스텝 크기 $`h`$의 리처드슨 외삽 값은 스텝 크기 $`h/2`$의 5점 중심 차분 값과 같다(예: $`h = 0.5`$의 외삽 값 3.1796875000과 $`h = 0.25`$의 5점 값). $`k = h/2`$라 하면 다음과 같이 두 식이 같아지기 때문이다.

$$
\frac{4D(k) - D(2k)}{3} = \frac{8\left[f(x+k) - f(x-k)\right] - \left[f(x+2k) - f(x-2k)\right]}{12k}
$$

이 밖에도 함수는 노트북 2.1절의 수렴 그래프, Exercise 2.1의 $`f'(1.5)`$ 추정, 3절의 고차 공식 비교, 5절의 스텝 크기 분석과 복소 스텝 방법과의 비교에 쓰인다. 5절의 셀은 중심 차분의 최적 스텝 크기를 $`2.24 \times 10^{-6}`$으로 출력하고, $`h = 10^{-5}`$에서 중심 차분의 오차를 $`2.78 \times 10^{-10}`$으로 보여 준다.

## 점검 문제

1. **분모의 크기:** 중심 차분 공식의 분모가 $`h`$가 아니라 $`2h`$인 이유는 무엇이며, $`h`$로 나누면 결과는 어떻게 되는가?

   <details>
   <summary>정답</summary>

   두 점 $`x - h`$와 $`x + h`$ 사이의 거리가 $`2h`$이기 때문이다. $`h`$로 나누면 기울기의 두 배인 약 $`2f'(x)`$를 얻는다. 기준 함수에서 $`h = 0.5`$이면 3.9 대신 7.8이 나온다.

   </details>

2. **평균과 중심 차분:** 전진 차분과 후진 차분의 평균이 중심 차분과 같음을 식으로 보이고, 이것이 오차의 차수와 어떤 관계가 있는지 설명하라.

   <details>
   <summary>정답</summary>

   $`\frac{1}{2}\left(\frac{f(x+h) - f(x)}{h} + \frac{f(x) - f(x-h)}{h}\right) = \frac{f(x+h) - f(x-h)}{2h}`$이다. 전진 차분의 오차는 $`\frac{f''}{2}h + \cdots`$, 후진 차분은 $`-\frac{f''}{2}h + \cdots`$로 1차 항의 부호가 반대여서, 평균을 내면 $`O(h)`$ 항이 사라지고 $`O(h^2)`$ 항이 남는다.

   </details>

3. **오차 비율:** 표 2에서 $`h`$를 0.5에서 0.25로 줄일 때 중심 차분의 오차 비율이 정확히 4가 아니라 4.03인 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   오차가 $`2.85h^2 + 0.1h^4`$이어서 $`h^4`$ 항이 있기 때문이다. $`h^4`$ 항은 $`h`$를 절반으로 줄일 때 16분의 1로 줄어 $`h^2`$ 항보다 빨리 작아지므로 비율이 4보다 조금 크다. $`h`$가 작아질수록 이 항의 비중이 줄어 비율이 4에 다가간다.

   </details>

4. **오차의 부호:** 표 2에서 중심 차분의 값이 모든 $`h`$에서 참값보다 큰 이유를 설명하라.

   <details>
   <summary>정답</summary>

   중심 차분의 오차는 $`\frac{f'''(x_0)}{6}h^2 + \frac{f^{(5)}}{120}h^4`$이고 $`f'''(0.5) = 17.1`$, $`f^{(5)} = 12`$가 모두 양수이므로 오차가 항상 양수이다.

   </details>

5. **리처드슨 외삽의 오차:** 중심 차분의 오차가 $`c_2 h^2 + c_4 h^4`$일 때 $`\frac{4D(h/2) - D(h)}{3}`$의 오차를 구하라.

   <details>
   <summary>정답</summary>

   $`\frac{4(c_2 h^2/4 + c_4 h^4/16) - (c_2 h^2 + c_4 h^4)}{3} = \frac{c_4 h^4/4 - c_4 h^4}{3} = -\frac{c_4}{4}h^4`$이다. 기준 함수에서 $`c_4 = 0.1`$이므로 $`-0.025h^4`$이다.

   </details>
