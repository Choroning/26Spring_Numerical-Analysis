## 3. 문제 1: 단순 선형 회귀의 계수

### 3.1 풀이 방법

노트북 2.1절의 공식에서 합 $`\sum`$은 `np.sum`, 평균 $`\bar{x}`$, $`\bar{y}`$는 `np.mean`으로 옮긴다. 절편 공식이 기울기를 쓰므로 `a1`을 먼저 계산한다.

$$
a_1 = \frac{n\sum x_i y_i - \sum x_i \sum y_i}{n\sum x_i^2 - \left(\sum x_i\right)^2}, \qquad a_0 = \bar{y} - a_1 \bar{x}
$$

노트북이 함께 적은 두 번째 형태는 분자와 분모를 $`n`$으로 나눈 같은 식이다. 절편 공식은 최소제곱 직선이 언제나 점 $`(\bar{x}, \bar{y})`$를 지난다는 뜻이기도 하다. 정규 방정식의 유도와 계수 풀이는 [14장 강의 노트](../../Lecture-Notes/Ch14_Linear-Regression/Concepts_Lecture.ko.md)의 4.3, 4.4절에서 다룬다.

### 3.2 작성한 코드

```python
    a1 = (n*np.sum(xi*yi) - np.sum(xi)*np.sum(yi)) / (n*np.sum(xi**2) - np.sum(xi)**2)
    a0 = np.mean(yi) - a1 * np.mean(xi)
```

### 3.3 실행 결과와 검증

```text
Slope     a1 = 0.210357 mm/kN
Intercept a0 = 0.000000 mm
Stiffness  k = 1/a1 = 4.7538 kN/mm
```

출력은 배포 노트북에 실린 출력과 같다. 보 처짐 데이터에서 $`n = 8`$, $`\sum x_i = 280`$, $`\sum y_i = 58.9`$, $`\sum x_i y_i = 2945`$, $`\sum x_i^2 = 14000`$이므로 손으로 계산하면 다음과 같다.

$$
a_1 = \frac{8 \times 2945 - 280 \times 58.9}{8 \times 14000 - 280^2} = \frac{7068}{33600} = 0.210357
$$

$`\bar{x} = 35`$, $`\bar{y} = 7.3625`$이고 $`7068 \times 35 / 33600 = 7.3625`$가 정확히 성립하므로 $`a_0 = \bar{y} - a_1 \bar{x} = 0`$이다. 이 데이터에서는 점 $`(\bar{x}, \bar{y})`$를 지나는 최소제곱 직선이 원점도 지나며, 처짐이 하중에 비례한다는 해석과 맞는다. 강성은 $`k = 1/a_1 = 4.7538`$ kN/mm이다. 이어지는 비교 셀은 같은 데이터를 `scipy.stats.linregress`와 `np.polyfit`으로도 적합한다.

```text
=== Method Comparison ===
Method                        a1 (slope)    a0 (intercept)          R2
------------------------------------------------------------------------
Our linreg                    0.21035714        0.00000000  0.99974064
scipy.stats.linregress        0.21035714        0.00000000  0.99974064
np.polyfit(deg=1)             0.21035714       -0.00000000
```

세 방법의 기울기가 소수점 아래 8자리까지 같다. `np.polyfit`의 `-0.00000000`은 절편이 0에 가까운 음수로 계산된 반올림 오차이다.

## 4. 문제 2: 적합도 통계량

### 4.1 풀이 방법

표 1의 정의를 그대로 옮긴다. `SST`는 관측값과 평균의 차의 제곱합, `SSE`는 관측값과 예측값의 차(잔차)의 제곱합이며, `SSR`은 그 차이, `R2`는 $`1 - S_r/S_T`$이다. 빈칸 뒤의 코드는 이 값들로 추정의 표준 오차 $`s_e = \sqrt{S_r/(n - p)}`$와 수정 결정 계수(adjusted $`R^2`$)를 계산하며, $`p`$는 매개변수의 개수 `n_params`이다. SST, SSE, SSR의 분해와 결정 계수는 [14장 강의 노트](../../Lecture-Notes/Ch14_Linear-Regression/Concepts_Lecture.ko.md)의 5절에서 다룬다.

### 4.2 작성한 코드

```python
    SST = np.sum((yi - y_bar)**2)   # total sum of squares
    SSE = np.sum((yi - yi_hat)**2)  # residual sum of squares
    SSR = SST - SSE                 # regression sum of squares
    R2  = 1 - SSE / SST             # coefficient of determination
```

### 4.3 실행 결과와 검증

```text
=== Goodness of Fit: Beam Deflection (Linear) ===
SST    = 185.898750   (total variation)
SSE    = 0.048214   (residual/unexplained)
SSR    = 185.850536   (explained by model)
R2     = 0.99974064
Adj R2 = 0.99969742
se     = 0.089642 mm
SST = SSR + SSE? True
```

출력은 배포 노트북에 실린 출력과 같다. `SST`는 노트북 1.3절의 표본 통계 셀이 출력한 `SST (corrected) = 185.898750`과 같고, 이는 표본 표준 편차 5.1533으로 계산한 $`(n-1)s_y^2 = 7 \times 5.1533^2`$과 일치한다. 나머지 값은 다음과 같이 확인된다.

- $`R^2 = 1 - 0.048214 / 185.898750 = 0.99974064`$
- $`s_e = \sqrt{0.048214 / (8 - 2)} = 0.089642`$
- 수정 결정 계수 $`= 1 - (0.048214 / 6) / (185.898750 / 7) = 0.99969742`$

> **참고:** 마지막 줄의 `SST = SSR + SSE? True`는 코드가 `SSR`을 `SST - SSE`로 정의했으므로 언제나 참이다. 내용이 있는 항등식은 설명된 제곱합 $`\sum(\hat{y}_i - \bar{y})^2`$이 $`S_T - S_r`$과 같다는 것이며, 이는 절편이 있는 최소제곱 적합에서 성립한다. 보 처짐 직선에서 $`\sum(\hat{y}_i - \bar{y})^2`$을 따로 계산해도 185.850536으로 `SSR`과 같다.

## 5. 문제 3: 거듭제곱 모델의 선형화

### 5.1 풀이 방법

자료를 `np.log10`으로 변환해 $`X = \log_{10} x`$, $`Y = \log_{10} y`$를 만들면, 빈칸 사이의 `linreg(X, Y)`가 로그 공간의 직선 $`Y = A_0 + A_1 X`$를 적합한다. 노트북 3.1절의 관계에 따라 기울기가 지수이고 절편이 계수의 상용로그이므로 $`\beta = A_1`$, $`\alpha = 10^{A_0}`$으로 되찾는다. 거듭제곱 모델의 선형화는 [15장 강의 노트](../../Lecture-Notes/Ch15_Nonlinear-Regression/Concepts_Lecture.ko.md)의 2.2절에서 다룬다.

### 5.2 작성한 코드

```python
    X = np.log10(xi)
    Y = np.log10(yi)
```

```python
    alpha = 10**A0
    beta  = A1
```

### 5.3 실행 결과와 검증

```text
Power law fit:  y = 0.2741 * x^1.9842
Exponent beta ~ 1.98  (response ~ stress squared)

Linear:    R2=0.88049,  se=189.79
Power law: R2=0.80882,  se=240.04
```

출력은 배포 노트북에 실린 출력과 같다. 같은 계산을 다시 하면 로그 공간의 절편과 기울기는 $`A_0 = -0.56203`$, $`A_1 = 1.98418`$이고, $`10^{-0.56203} = 0.27414`$로 출력의 $`\alpha`$와 일치한다.

눈여겨볼 점은 원래의 $`y`$ 공간에서 계산한 $`R^2`$이 거듭제곱 모델(0.80882)보다 직선(0.88049)에서 더 크다는 것이다. 로그 공간에서 같은 직선의 결정 계수를 계산하면 0.948로 높다. 로그 선형화는 $`\log y`$의 잔차 제곱합을 최소화하므로 상대 오차를 고르게 줄이고, 그 결과 1220, 830, 1450처럼 큰 응답에서 생기는 절대 오차는 원래 공간의 SSE에 크게 남는다. 노트북 5절의 비교 셀은 같은 모델을 `curve_fit`으로 원래 공간에서 적합해 이 차이를 보여 준다.

```text
=== Power Law: Log-linearization vs. curve_fit ===
                               alpha          beta          R2
--------------------------------------------------------------
Log-linearization           0.274137      1.984176    0.808818
curve_fit                   2.538367      1.435856    0.876898
curve_fit std err           3.620273      0.340430

Note: curve_fit minimizes SSE in the original y-space;
      log-linearization minimizes SSE in log(y) space.
```

원래 공간의 SSE를 직접 최소화한 `curve_fit`의 $`R^2`$(0.876898)이 로그 선형화의 값보다 크다. 그래도 직선보다 조금 작은데, 직선 $`a_0 + a_1 x`$에는 절편이 있지만 $`\alpha x^\beta`$는 원점을 지나야 하므로 두 모델이 서로 다른 함수족이기 때문이다.

## 6. 문제 4: 다항 회귀의 정규 방정식

### 6.1 풀이 방법

$`m`$차 다항식의 기저 함수는 $`z_j(x) = x^j`$이므로 설계 행렬의 $`j`$번째 열은 `xi**j`이다. $`j = 0`$이면 모든 원소가 1인 열이 되어 상수항을 맡는다. 계수는 정규 방정식을 `np.linalg.solve`로 풀어 구하며, 역행렬 $`(\mathbf{X}^T\mathbf{X})^{-1}`$을 따로 계산하지 않는다. 다항 회귀와 일반 선형 최소제곱 회귀의 정규 방정식은 [15장 강의 노트](../../Lecture-Notes/Ch15_Nonlinear-Regression/Concepts_Lecture.ko.md)의 3, 5절에서 다룬다.

### 6.2 작성한 코드

```python
        X[:, j] = xi**j  # (j-th column = x to the power j)
```

```python
    c = np.linalg.solve(X.T @ X, X.T @ yi)
```

### 6.3 실행 결과와 검증

```text
Quadratic: y = 2.4786 + 2.3593t + 1.8607t²
```

출력은 배포 노트북에 실린 출력과 같다. 같은 데이터에 `np.polyfit(x_vel, y_vel, 2)`를 적용하면 내림차순으로 $`[1.86071, 2.35929, 2.47857]`$을 돌려주어 계수가 일치한다. 셀이 그리는 그림의 범례에는 각 차수의 $`R^2`$과 $`s_e`$가 표시되며, 그 값은 다음과 같다.

| 차수 | $`R^2`$ | $`s_e`$ |
|:-----|:-----|:-----|
| 1 | 0.94708 | 5.766 |
| 2 | 0.99851 | 1.118 |
| 3 | 0.99866 | 1.299 |

*표 2. 속도 데이터에 적합한 다항식의 차수별 적합도*

$`R^2`$은 차수가 오를 때마다 커지지만, 3차에서 $`s_e = \sqrt{S_r/(n - m - 1)}`$은 오히려 커진다. 매개변수 하나를 더한 만큼 SSE가 충분히 줄지 않았다는 뜻이므로, 셀의 주석이 예상한 대로 2차 모델이 적절하다.

`poly_lstsq`는 노트북 6절의 모델 비교 셀에서도 쓰인다. 이 셀은 표준화한 온도로 점성 데이터 13개에 1~8차 다항식을 적합한다.

## 7. 문제 5: Antoine 방정식의 비선형 회귀

### 7.1 풀이 방법

노트북 5.1절이 제시한 형식대로 `curve_fit(모델 함수, x 데이터, y 데이터, p0=초기 추정값)`을 호출한다. 모델 함수 `antoine_model(T, A, B, C)`는 첫 인자가 독립 변수이고 나머지가 추정할 매개변수이므로 `curve_fit`이 요구하는 형식과 맞는다. 비선형 최소제곱은 반복법이므로 초기 추정값이 필요하며, 셀이 준 `p0_ant = [8.0, 1500.0, 200.0]`을 넘긴다. 돌려받는 `popt_ant`는 최적 매개변수, `pcov_ant`는 그 공분산 행렬이다. 비선형 회귀와 Antoine 방정식은 [15장 강의 노트](../../Lecture-Notes/Ch15_Nonlinear-Regression/Concepts_Lecture.ko.md)의 6절에서 다룬다.

### 7.2 작성한 코드

```python
popt_ant, pcov_ant = curve_fit(antoine_model, T_ant, P_ant, p0=p0_ant)
```

### 7.3 실행 결과와 검증

```text
=== Antoine Equation Fit (water vapor pressure) ===
A = 7.997574 +/- 0.007401
B = 1687.0509 +/- 4.6041
C = 229.7113 +/- 0.4237
R2 = 0.99999999
Literature: A=8.07131, B=1730.63, C=233.426
```

출력은 배포 노트북에 실린 출력과 같다. 적합한 매개변수로 계산한 증기압은 55.28, 92.51, 149.40, 233.70, 355.14, 525.75, 760.02 mmHg로, 데이터와의 차가 모두 0.05 mmHg 이하이다.

적합 결과는 문헌값과 다르지만 둘 다 데이터를 잘 설명한다. 문헌값으로 계산한 증기압은 55.19, 92.30, 149.04, 233.17, 354.53, 525.27, 760.09 mmHg이고 $`R^2 = 0.9999973`$이다. SSE는 문헌값이 1.07, 적합 결과가 0.0050이므로, `curve_fit`은 이 7개 점에 더 가까운 매개변수를 찾은 것이다. `pcov_ant`에서 계산한 매개변수 사이의 상관 계수는 $`A`$와 $`B`$가 0.99964, $`A`$와 $`C`$가 0.99847, $`B`$와 $`C`$가 0.99959로 1에 가깝다. 한 매개변수의 변화를 다른 매개변수가 거의 상쇄하므로, 서로 다른 매개변수 집합이 이 온도 구간에서 거의 같은 곡선을 준다.

## 점검 문제

1. **원점을 지나는 직선:** 문제 1에서 절편이 정확히 0으로 나온 이유를 최소제곱 직선의 성질로 설명하라.

   <details>
   <summary>정답</summary>

   최소제곱 직선은 $`a_0 = \bar{y} - a_1 \bar{x}`$이므로 언제나 $`(\bar{x}, \bar{y}) = (35, 7.3625)`$를 지난다. 이 데이터에서는 $`a_1 \bar{x} = 7068 \times 35 / 33600 = 7.3625 = \bar{y}`$가 정확히 성립하므로 $`a_0 = 0`$이 되어 직선이 원점도 지난다.

   </details>

2. **항상 참인 확인:** 문제 2의 출력에서 `SST = SSR + SSE? True`가 적합의 좋고 나쁨과 관계없이 참인 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   코드가 `SSR = SST - SSE`로 정의하므로 `SSR + SSE`는 정의상 `SST`와 같다. 의미 있는 확인은 $`\sum(\hat{y}_i - \bar{y})^2`$을 따로 계산해 $`S_T - S_r`$과 비교하는 것이며, 이 등식은 절편이 있는 최소제곱 적합에서 성립한다.

   </details>

3. **거듭제곱 모델의 낮은 R²:** 문제 3에서 거듭제곱 모델의 $`R^2`$이 직선보다 낮게 나온 이유를 설명하라.

   <details>
   <summary>정답</summary>

   로그 선형화는 $`\log_{10} y`$의 잔차 제곱합을 최소화하므로 원래 공간의 SSE를 최소화하지 않는다. 큰 응답 값에서 생기는 절대 오차가 원래 공간의 SSE에 크게 남아 $`R^2`$이 0.80882로 낮아진다. 같은 모델을 `curve_fit`으로 원래 공간에서 적합하면 $`R^2`$이 0.876898로 높아진다.

   </details>

4. **3차 다항식의 s_e:** 문제 4의 속도 데이터에서 3차 다항식의 $`R^2`$이 2차보다 큰데도 $`s_e`$가 커진 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   $`s_e = \sqrt{S_r/(n - m - 1)}`$은 매개변수 개수가 늘면 분모가 줄어든다. 3차 항을 더해 $`S_r`$은 3.75에서 3.37로 약 10% 줄었지만 분모는 3에서 2로 줄었으므로, $`s_e`$가 1.118에서 1.299로 커졌다. 추가한 항이 적합을 의미 있게 개선하지 못했다는 뜻이다.

   </details>

5. **문헌값과 다른 매개변수:** 문제 5의 적합 매개변수가 문헌값과 다른데도 $`R^2`$이 1에 가까운 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   $`A`$, $`B`$, $`C`$ 사이의 상관 계수가 0.998 이상으로 1에 가까워, 한 매개변수의 변화를 다른 매개변수가 거의 상쇄한다. 그래서 문헌값과 적합 결과처럼 서로 다른 매개변수 집합이 40~100 °C 구간에서 거의 같은 곡선을 준다. 문헌값의 $`R^2`$도 0.9999973이며, `curve_fit`은 이 7개 점의 SSE를 1.07에서 0.0050으로 더 줄인 매개변수를 찾았다.

   </details>
