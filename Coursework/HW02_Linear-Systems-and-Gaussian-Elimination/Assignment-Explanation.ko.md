## 3. 문제 1: 질량-스프링 시스템의 우변 벡터

### 3.1 풀이 방법

행렬 `A`의 $`i`$번째 행은 질량 $`m_i`$의 힘의 평형식이고, 그 식의 우변은 질량 $`m_i`$에 작용하는 외력 $`F_i`$이다. 따라서 우변 벡터는 외력을 질량의 번호 순서대로 늘어놓은 $`[F_1, F_2, F_3]`$이다. 순서가 어긋나면 힘이 다른 질량의 평형식에 들어가 다른 시스템을 풀게 된다. 강성 행렬의 유도는 [8장 강의 노트](../../Lecture-Notes/Ch08_Linear-Algebraic-Equations/Concepts_Lecture.ko.md)의 2.11절과 [8장 실습 노트](../../Lecture-Notes/Ch08_Linear-Algebraic-Equations/Concepts_Lab.ko.md)의 2절에서 다룬다.

### 3.2 작성한 코드

```python
b = np.array([F1, F2, F3])
```

### 3.3 실행 결과와 검증

```text
Coefficient matrix A:
[[ 70. -30.   0.]
 [-30.  50. -20.]
 [  0. -20.  30.]]

Right-hand side b: [20. 40. 30.]
```

```text
Displacements:
  x1 = 1.520000 m
  x2 = 2.880000 m
  x3 = 2.920000 m

Residual A*x - b = [ 0.00000000e+00 -2.84217094e-14 -1.42108547e-14]
Max |residual|   = 2.84e-14  (machine precision: ~2e-16)
```

변위를 각 식에 대입하면 $`70(1.52) - 30(2.88) = 20`$, $`-30(1.52) + 50(2.88) - 20(2.92) = 40`$, $`-20(2.88) + 30(2.92) = 30`$으로 세 식이 모두 성립한다. 잔차의 최댓값 $`2.84 \times 10^{-14}`$는 머신 엡실론 $`2.2 \times 10^{-16}`$보다 크게 보이지만, 우변의 크기가 40 정도이므로 상대적으로는 $`2.84 \times 10^{-14} / 40 \approx 7 \times 10^{-16}`$, 곧 머신 엡실론의 몇 배 수준이다. 잔차는 우변의 크기와 함께 비교해야 한다.

## 4. 문제 2: 단순 Gauss 소거법

### 4.1 풀이 방법

**전진 소거:** 피봇 열 `k`에서 행 `i`의 소거 계수는 이미 앞 단계로 변형된 확대 행렬의 성분으로 계산한다.

$$
f_{ik} = \frac{a_{ik}^{(k)}}{a_{kk}^{(k)}}
$$

그런 다음 행 `i`에서 행 `k`의 $`f_{ik}`$배를 빼서 $`(i, k)`$ 성분을 0으로 만든다. 행 `i`의 앞쪽 열 `0`부터 `k-1`까지는 이전 단계에서 이미 0이 되었으므로, 갱신은 열 `k`부터 마지막 열 `nb-1`까지의 슬라이스 `k:nb`에만 하면 된다. 마지막 열에는 우변이 들어 있으므로 같은 갱신이 우변에도 적용된다. 계수를 먼저 변수 `factor`에 저장해야 한다는 점도 중요하다. 행 갱신이 `Aug[i, k]`를 덮어쓰기 때문이다.

**후진 대입:** 전진 소거가 끝나면 확대 행렬의 마지막 열(`nb-1`)에 변형된 우변이 남는다. 마지막 행은 미지수가 하나뿐이므로 `x[n-1]`을 바로 구하고, 그 위의 행은 이미 구한 미지수들을 대입해 푼다. 노트북 2.3절의 합 $`\sum_{j=i+1}^{n-1} a_{ij} x_j`$는 행 벡터 `Aug[i, i+1:n]`과 `x[i+1:n]`의 내적 `@`으로 한 번에 계산된다. 단순 Gauss 소거법은 [8장 강의 노트](../../Lecture-Notes/Ch08_Linear-Algebraic-Equations/Concepts_Lecture.ko.md)의 6절과 [8장 실습 노트](../../Lecture-Notes/Ch08_Linear-Algebraic-Equations/Concepts_Lab.ko.md)의 3절에서 다룬다.

### 4.2 작성한 코드

```python
            factor = Aug[i, k] / Aug[k, k]
            Aug[i, k:nb] = Aug[i, k:nb] - factor * Aug[k, k:nb]
```

```python
    x[n-1] = Aug[n-1, nb-1] / Aug[n-1, n-1]
    for i in range(n - 2, -1, -1):
        x[i] = (Aug[i, nb-1] - Aug[i, i+1:n] @ x[i+1:n]) / Aug[i, i]
```

### 4.3 실행 결과와 검증

```text
Upper triangular augmented matrix after elimination:
[[ 2.   1.  -1.   8. ]
 [ 0.   0.5  0.5  1. ]
 [ 0.   0.  -1.   1. ]]

Solution x  = [ 2.  3. -1.]
Expected    = [2, 3, -1]
Residual    = [0. 0. 0.]
```

```text
Spring-mass displacements:
  Gauss Elimination : [1.52 2.88 2.92]
  np.linalg.solve   : [1.52 2.88 2.92]
  Max difference    : 0.00e+00
```

소거 후의 확대 행렬은 노트북 2.4절이 손으로 추적한 결과 $`[0, 1/2, 1/2 \mid 1]`$, $`[0, 0, -1 \mid 1]`$과 같고, 해도 참해 $`(2, 3, -1)`$과 일치한다. 질량-스프링 시스템에서도 `np.linalg.solve`와의 차이가 0으로 출력된다. 이 시스템은 각 단계의 피봇(70과 $`50 - 30 \cdot 30/70 \approx 37.1`$)이 그 열에서 절댓값이 가장 크므로, 행을 바꾸지 않는 단순 소거법으로도 안전하게 풀린다.

## 5. 문제 3: 부분 피봇팅

### 5.1 풀이 방법

먼저 피봇팅이 없을 때 일어나는 일을 확인한다. 노트북 3.1절의 셀은 첫 피봇이 0인 시스템에 `gauss_naive`를 적용하며, 완성한 노트북의 출력은 다음과 같다.

```text
True solution (via numpy):
  x = [ 0.5942029  -0.01449275  0.56521739]

Naive Gaussian Elimination result:
  x = [nan nan nan]
Augmented matrix after elimination:
[[  0.  -3.   7.   4.]
 [ nan  inf -inf -inf]
 [ nan  nan  nan  nan]]
```

`factor = Aug[1, 0] / Aug[0, 0] = 1/0`이 `inf`가 되고, 그 뒤의 연산에서 $`0 \cdot \infty`$와 $`\infty - \infty`$가 `nan`을 만들어 해 전체가 `nan`이 된다. 셀은 이때 0으로 나누기에 관한 `RuntimeWarning`도 출력한다.

부분 피봇팅은 소거 전에 행 `k`와 행 `imax`를 맞바꾼다. NumPy에서 `Aug[[k, imax]]`처럼 정수 배열로 행을 고르면 그 행들의 복사본이 만들어지므로, `Aug[[k, imax]] = Aug[[imax, k]]`는 오른쪽의 복사본을 먼저 만든 뒤 두 행에 거꾸로 대입하여 안전하게 맞바꾼다. 행 전체를 바꾸므로 우변(마지막 열)도 함께 바뀐다. 부분 피봇팅은 [9장 강의 노트](../../Lecture-Notes/Ch09_Gauss-Elimination/Concepts_Lecture.ko.md)의 1절과 [9장 실습 노트](../../Lecture-Notes/Ch09_Gauss-Elimination/Concepts_Lab.ko.md)의 1절에서 다룬다.

> **주의:** `Aug[k], Aug[imax] = Aug[imax], Aug[k]`처럼 정수 하나로 행을 고르면 복사본이 아니라 원래 배열의 뷰(view)가 오른쪽에 놓인다. 첫 대입이 행 `k`를 행 `imax`의 값으로 덮어쓴 뒤 두 번째 대입이 이미 바뀐 행 `k`를 행 `imax`에 다시 쓰므로, 두 행이 모두 원래의 행 `imax`가 되어 교환이 일어나지 않는다.

### 5.2 작성한 코드

```python
            Aug[[k, imax]] = Aug[[imax, k]]
```

### 5.3 실행 결과와 검증

```text
Gauss with partial pivoting:
  x       = [ 0.5942029  -0.01449275  0.56521739]
  x (ref) = [ 0.5942029  -0.01449275  0.56521739]
  Max error: 0.00e+00

Upper triangular augmented matrix after pivoting:
[[ 5.  -2.   0.   3. ]
 [ 0.  -3.   7.   4. ]
 [ 0.   0.   4.6  2.6]]
```

소거 과정을 손으로 따라가면 출력의 상삼각 행렬이 나온다.

- **$`k = 0`$:** 0열의 값 $`0, 1, 5`$ 가운데 5가 가장 크므로 0행과 2행을 바꾼다. 소거 계수 $`1/5 = 0.2`$로 1행은 $`[0, 2.4, -1 \mid -0.6]`$이 되고, 2행으로 내려간 원래의 0행은 0열이 이미 0이어서 그대로 $`[0, -3, 7 \mid 4]`$이다.
- **$`k = 1`$:** 1열의 아래쪽 값 $`2.4`$와 $`-3`$ 가운데 절댓값이 큰 $`-3`$을 피봇으로 삼아 두 행을 다시 바꾼다. 소거 계수 $`2.4/(-3) = -0.8`$로 2행은 $`[0, 0, 4.6 \mid 2.6]`$이 된다.
- **후진 대입:** $`x_3 = 2.6/4.6 = 0.565217`$, $`x_2 = (4 - 7 x_3)/(-3) = -0.014493`$, $`x_1 = (3 + 2 x_2)/5 = 0.594203`$으로 `np.linalg.solve`의 해와 같다.

$`k = 1`$의 피봇 2.4는 0이 아닌데도 교환이 일어난다. 부분 피봇팅은 피봇이 0인지가 아니라 열에서 절댓값이 가장 큰지를 기준으로 하므로, 소거 계수가 항상 $`|f_{ik}| \leq 1`$이 된다.

## 6. 문제 4: Thomas 알고리즘

### 6.1 풀이 방법

삼중대각 행렬에서는 피봇 행 $`k-1`$의 0이 아닌 성분이 대각 성분 $`f_{k-1}`$과 위 대각 성분 $`g_{k-1}`$뿐이다. 따라서 행 $`k`$의 아래 대각 성분 $`e_k`$를 소거하는 Gauss 소거는 소거 계수 $`e_k / f_{k-1}`$를 구한 뒤 대각 성분과 우변 두 곳만 갱신하면 된다.

$$
f_k \leftarrow f_k - \frac{e_k}{f_{k-1}} g_{k-1}, \qquad r_k \leftarrow r_k - \frac{e_k}{f_{k-1}} r_{k-1}
$$

루프가 $`k`$ 순서로 진행되므로 `f[k-1]`과 `r[k-1]`은 앞 반복에서 이미 갱신된 값이며, 이것이 Gauss 소거의 $`a_{kk}^{(k)}`$에 해당한다. 함수는 처음에 `f`와 `r`의 복사본을 만들어 호출자의 배열을 바꾸지 않는다. Thomas 알고리즘은 [9장 강의 노트](../../Lecture-Notes/Ch09_Gauss-Elimination/Concepts_Lecture.ko.md)의 5절과 [9장 실습 노트](../../Lecture-Notes/Ch09_Gauss-Elimination/Concepts_Lab.ko.md)의 3절에서 다룬다.

### 6.2 작성한 코드

```python
        factor = e[k] / f[k-1]
        f[k] = f[k] - factor * g[k-1]
        r[k] = r[k] - factor * r[k-1]
```

### 6.3 실행 결과와 검증

열전도 셀은 그림만 그리므로, 같은 함수로 내부 절점이 3개인 경우를 계산하면 다음과 같다.

| 절점 | $`x`$ (m) | 수치해 $`T`$ (°C) | 선형 분포 $`50 + 100x`$ (°C) |
|:-----|:-----|:-----|:-----|
| 1 | 0.25 | 75.0 | 75.0 |
| 2 | 0.50 | 100.0 | 100.0 |
| 3 | 0.75 | 125.0 | 125.0 |

*표 2. 내부 절점 3개로 푼 1차원 정상상태 열전도의 온도*

내부 절점이 6개, 15개인 경우도 선형 분포와의 차이가 $`3 \times 10^{-14}`$ 이하이다. 선형 함수는 2계 차분 $`T_{i-1} - 2T_i + T_{i+1}`$을 정확히 0으로 만들므로, 이 문제에서는 이산화 오차 없이 절점 값이 엄밀해와 같아야 하고 실제로 그렇다. 또한 이 행렬은 내부 행에서 $`|f_i| = |e_i| + |g_i|`$여서 엄격한 대각 우위가 아니지만, 전진 소거 뒤의 대각 성분은 $`f_k = -(k+2)/(k+1)`$, 곧 $`-2, -1.5, -1.333, \ldots`$로 0이 되지 않으므로 피봇팅 없이 풀 수 있다.

노트북 4.3절 다음의 셀은 같은 삼중대각 시스템을 Thomas 알고리즘과 `np.linalg.solve`로 풀어 시간을 비교한다. 완성한 노트북의 출력은 다음과 같다.

```text
     n    Thomas (s)    Full Gauss (s)     Speedup
----------------------------------------------------
   100      0.000071          0.000094         1.3x
   500      0.000403          0.001319         3.3x
  2000      0.001310          0.032362        24.7x
  5000      0.003320          0.553740       166.8x
```

시간은 실행 환경에 따라 달라지지만, $`n`$이 커질수록 속도 차이가 벌어진다. Thomas 알고리즘의 시간은 $`n`$에 거의 비례해 늘고, 밀집 행렬을 푸는 쪽은 $`O(n^3)`$이어서 훨씬 빠르게 늘기 때문이다.

## 점검 문제

1. **계수를 먼저 저장하는 이유:** 문제 2에서 `Aug[i, k:nb] = Aug[i, k:nb] - Aug[i, k] / Aug[k, k] * Aug[k, k:nb]`처럼 계수를 따로 저장하지 않고 한 줄로 쓰면 결과가 달라지는가?

   <details>
   <summary>정답</summary>

   이 한 줄에서는 달라지지 않는다. NumPy는 오른쪽 식 전체를 계산한 뒤 왼쪽에 대입하므로 `Aug[i, k]`가 덮어쓰이기 전의 값이 쓰인다. 그러나 열마다 루프를 돌며 `Aug[i, j]`를 하나씩 갱신하는 구현에서는 `j = k`에서 `Aug[i, k]`가 0으로 바뀐 뒤 나머지 열의 계수가 0이 되어 소거가 틀어진다. 계수를 먼저 저장하면 구현 방식과 관계없이 안전하다.

   </details>

2. **피봇이 0인 시스템:** 문제 3의 예제에서 단순 소거법이 `nan`을 내는 과정을 설명하라.

   <details>
   <summary>정답</summary>

   $`k = 0`$에서 1행의 소거 계수가 $`1/0 = \infty`$가 되고, 1행 갱신에서 $`1 - \infty \cdot 0`$ 같은 연산이 `nan`을, 나머지 열에서 `inf`를 만든다. 이 값들이 이후 소거와 후진 대입으로 퍼져 해의 모든 성분이 `nan`이 된다.

   </details>

3. **행 교환의 함정:** `Aug[k], Aug[imax] = Aug[imax], Aug[k]`가 두 행을 맞바꾸지 못하는 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   정수 하나로 고른 `Aug[imax]`와 `Aug[k]`는 원래 배열의 뷰이다. 첫 대입으로 행 `k`가 행 `imax`의 값이 된 뒤 두 번째 대입이 바뀐 행 `k`의 값을 행 `imax`에 쓰므로, 두 행이 모두 원래의 행 `imax`가 된다. `Aug[[k, imax]] = Aug[[imax, k]]`는 오른쪽이 복사본이어서 이 문제가 없다.

   </details>

4. **Thomas 알고리즘의 피봇:** 문제 4의 열전도 행렬은 엄격한 대각 우위가 아닌데도 피봇팅 없이 풀린다. 그 이유를 전진 소거 뒤의 대각 성분으로 설명하라.

   <details>
   <summary>정답</summary>

   $`f_0 = -2`$에서 시작해 $`f_k = -2 - 1/f_{k-1}`$을 반복하면 $`f_k = -(k+2)/(k+1)`$이 되어 $`-2, -1.5, -1.333, \ldots`$로 $`-1`$에 다가갈 뿐 0이 되지 않는다. 따라서 나눗셈에 쓰이는 피봇이 0이 되는 일이 없다.

   </details>

5. **이산화 오차가 없는 이유:** 문제 4의 열전도 수치해가 내부 절점의 개수와 관계없이 엄밀해와 같은 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   엄밀해 $`T = 50 + 100x`$는 선형이므로 같은 간격의 세 점에서 $`T_{i-1} - 2T_i + T_{i+1} = 0`$을 정확히 만족한다. 이산화된 식이 엄밀해의 절점 값을 그대로 해로 가지므로, 차이는 반올림 오차 수준만 남는다.

   </details>
