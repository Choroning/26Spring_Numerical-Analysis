## 3. 문제 1: 행렬 분할

### 3.1 풀이 방법

`np.tril(A, k)`는 $`k`$번째 대각선과 그 아래만 남기고, `np.triu(A, k)`는 $`k`$번째 대각선과 그 위만 남긴다. 주대각선이 $`k = 0`$이므로, 대각선 바로 아래부터 남기는 `np.tril(A, -1)`이 엄밀 하삼각 부분 $`L`$, 대각선 바로 위부터 남기는 `np.triu(A, 1)`이 엄밀 상삼각 부분 $`U`$이다. 대각 부분은 배포된 코드가 `np.diag(np.diag(A))`로 구해 두었다. 안쪽 `np.diag`가 대각 성분의 벡터를 꺼내고, 바깥쪽 `np.diag`가 그 벡터로 대각 행렬을 만든다. 행렬 분할은 [12장 강의 노트](../../Lecture-Notes/Ch12_Iterative-Methods/Concepts_Lecture.ko.md)의 4.1절에서 다룬다.

> **주의:** 여기의 $`L`$과 $`U`$는 HW3의 LU 분해에 나오는 $`L`$, $`U`$와 다른 대상이다. LU 분해는 곱 $`A = LU`$이고 $`L`$의 대각이 1이지만, 행렬 분할은 합 $`A = D + L + U`$이고 $`L`$과 $`U`$의 대각은 0이다.

### 3.2 작성한 코드

```python
    L = np.tril(A, -1)                               # (strictly lower)
    U = np.triu(A,  1)                               # (strictly upper)
```

### 3.3 실행 결과와 검증

```text
D =
 [[ 3.  0.  0.]
 [ 0.  7.  0.]
 [ 0.  0. 10.]]
L =
 [[ 0.   0.   0. ]
 [ 0.1  0.   0. ]
 [ 0.3 -0.2  0. ]]
U =
 [[ 0.  -0.1 -0.2]
 [ 0.   0.  -0.3]
 [ 0.   0.   0. ]]

Sanity check  D + L + U - A =
 [[0. 0. 0.]
 [0. 0. 0.]

```

출력은 배포 노트북에 실린 출력과 같다. $`L`$에는 $`a_{21} = 0.1`$, $`a_{31} = 0.3`$, $`a_{32} = -0.2`$만, $`U`$에는 $`a_{12} = -0.1`$, $`a_{13} = -0.2`$, $`a_{23} = -0.3`$만 남았고, 세 부분의 합이 정확히 $`A`$이다. 이 분할은 노트북 4.2절의 함수 `iteration_matrices`가 반복행렬 $`T_J = -D^{-1}(L+U)`$와 $`T_{GS} = -(D+L)^{-1}U`$를 만드는 데 그대로 쓰인다.

## 4. 문제 2: 야코비 반복법

### 4.1 풀이 방법

함수는 미리 `d = np.diag(A)`(대각 성분의 벡터)와 `R = A - np.diag(d)`(대각을 뺀 부분 $`L + U`$)를 만들어 둔다. 야코비 반복의 행렬 형식 $`\mathbf{x}^{(k+1)} = D^{-1}(\mathbf{b} - (L+U)\mathbf{x}^{(k)})`$에서 $`D^{-1}`$을 곱하는 것은 각 성분을 대응하는 대각 성분으로 나누는 것과 같으므로, 한 번의 반복은 `(b - R @ x) / d`로 쓸 수 있다. `R @ x`의 $`i`$번째 성분이 $`\sum_{j \neq i} a_{ij} x_j`$이고, `/ d`는 성분별 나눗셈이다.

모든 성분이 이전 값 `x`만으로 계산되므로 결과는 새 배열 `x_new`에 담는다. 뒤의 코드가 `x_new`와 `x`의 차로 근사 상대 오차를 구한 뒤에야 `x = x_new`로 바꾼다. 야코비 반복법은 [12장 강의 노트](../../Lecture-Notes/Ch12_Iterative-Methods/Concepts_Lecture.ko.md)의 5절에서 다룬다.

### 4.2 작성한 코드

```python
        x_new = (b - R @ x) / d
```

### 4.3 실행 결과와 검증

```text

    2      3.000762     -2.488524      7.006357      6.078749
```

첫 반복은 $`\mathbf{x}^{(0)} = \mathbf{0}`$이므로 $`x_1 = 7.85/3 = 2.616667`$, $`x_2 = -19.3/7 = -2.757143`$, $`x_3 = 71.4/10 = 7.14`$이고, 출력과 같다. 반복표의 $`x`$ 값들은 시험 셀이 같은 식으로 따로 계산한 것이고 오차 열은 함수가 돌려준 목록이므로, 두 열이 서로 맞는다는 것은 함수가 같은 갱신을 수행한다는 뜻이다. 첫 반복의 오차가 100%인 것은 이전 값이 영벡터여서 $`\lVert \mathbf{x}^{(1)} - \mathbf{0} \rVert / \lVert \mathbf{x}^{(1)} \rVert = 1`$이기 때문이다.

허용 오차 `tol=1e-6`은 백분율로 해석되어 $`\varepsilon_a < 10^{-6}\%`$가 되는 8번째 반복에서 멈춘다. 노트북 4.2절은 이 행렬의 야코비 반복행렬의 스펙트럼 반경을 $`\rho(T_J) = 0.0482`$로 계산하며, 이는 반복마다 약 $`-\log_{10} 0.0482 \approx 1.3`$자리씩 정확해진다는 뜻이다. 오차 열이 반복마다 0.03~0.07배로 줄어드는 것과 맞는다.

## 5. 문제 3: 가우스-자이델 방법

### 5.1 풀이 방법

$`i`$번째 성분을 갱신할 때 대각 성분을 뺀 나머지 항의 합은 대각 왼쪽과 오른쪽의 두 내적으로 나뉜다.

$$
\sigma_i = \sum_{j < i} a_{ij} x_j + \sum_{j > i} a_{ij} x_j
$$

배열 `x`를 제자리에서 갱신하므로, 성분 $`i`$를 계산할 때 `x[:i]`에는 이번 반복에서 이미 갱신된 값이, `x[i+1:]`에는 아직 갱신되지 않은 이전 반복의 값이 들어 있다. 따라서 `A[i, :i] @ x[:i] + A[i, i+1:] @ x[i+1:]`이 가우스-자이델 공식의 두 합을 정확히 구현하며, 오른쪽 부분은 `x_old[i+1:]`로 써도 같은 값이다. 그다음 `x[i] = (b[i] - sigma) / A[i, i]`로 그 자리를 바로 바꾸면 다음 성분의 계산에 새 값이 쓰인다. 가우스-자이델 방법은 [12장 강의 노트](../../Lecture-Notes/Ch12_Iterative-Methods/Concepts_Lecture.ko.md)의 2절과 4절에서 다룬다.

> **주의:** `x[:i]` 대신 `x_old[:i]`를 쓰면 모든 성분이 이전 값으로 계산되어 야코비 반복법이 된다. 두 방법의 차이는 공식이 아니라 어떤 값을 언제 쓰는가에 있다.

### 5.2 작성한 코드

```python
            sigma = A[i, :i] @ x[:i] + A[i, i+1:] @ x[i+1:]
            x[i]  = (b[i] - sigma) / A[i, i]
```

### 5.3 실행 결과와 검증

| 3 | 3.000032 | -2.499988 | 6.999999 | 0.118354 |
| 4 | 3.000000 | -2.500000 | 7.000000 | 0.000421 |
| 5 | 3.000000 | -2.500000 | 7.000000 | 0.000004 |
| 6 | 3.000000 | -2.500000 | 7.000000 | 0.000000 |

*표 2. 가우스-자이델 방법의 반복값과 근사 상대 오차*

첫 반복의 값 $`2.6167`$, $`-2.7945`$, $`7.0056`$은 노트북 3.1절이 손으로 계산한 값과 같다. 둘째 성분부터 갱신된 $`x_1`$을 쓰므로 야코비의 첫 반복($`-2.757143`$, $`7.14`$)보다 참값에 가깝다.

수렴 속도의 차이는 스펙트럼 반경으로 설명된다. 노트북 4.2절의 출력에 따르면 이 행렬에서 $`\rho(T_J) = 0.0482`$, $`\rho(T_{GS}) = 0.0065`$이다. 같은 정확도에 필요한 반복 횟수는 대략 $`1/(-\log\rho)`$에 비례하므로 가우스-자이델은 야코비의 약 $`\log 0.0482 / \log 0.0065 \approx 0.6`$배가 필요하고, 실제로는 8회 대 6회였다.

노트북 3.2절의 열 네트워크에서도 가우스-자이델은 허용 오차 $`10^{-8}\%`$까지 13회 만에 수렴하며, 절점 온도 54.464286°C, 17.857143°C, 16.964286°C는 엄밀해 $`1525/28`$, $`125/7`$, $`475/28`$과 같다. 노트북 5절의 비교에서 같은 시스템에 야코비 반복법은 23회가 걸렸다. 이 행렬은 삼중대각이어서 $`\rho(T_{GS}) = \rho(T_J)^2`$ $`(0.125 = 0.3536^2)`$이 성립하므로, 가우스-자이델이 야코비의 약 절반의 반복으로 수렴한다.

## 6. 문제 4: 대각 우위 검사

### 6.1 풀이 방법

`np.abs(A)`의 행별 합 `np.sum(np.abs(A), axis=1)`은 $`\sum_j |a_{ij}|`$이므로, 여기서 대각 성분의 절댓값 `diag_abs`를 빼면 비대각 성분 절댓값의 합 $`\sum_{j \neq i} |a_{ij}|`$가 된다. 여유는 $`|a_{ii}| - \sum_{j \neq i} |a_{ij}|`$이고, 함수는 `strict=True`이면 모든 여유가 양수인지, `strict=False`이면 모두 0 이상인지로 판정한다. 배열 연산이므로 모든 행의 값이 한 번에 계산된다. 대각 우위는 [12장 강의 노트](../../Lecture-Notes/Ch12_Iterative-Methods/Concepts_Lecture.ko.md)의 3절과 8.4절에서 다룬다.

### 6.2 작성한 코드

```python
    offdiag_sum = np.sum(np.abs(A), axis=1) - diag_abs  # row sums of |A| minus the diagonal
    margins = diag_abs - offdiag_sum
```

### 6.3 실행 결과와 검증

```text
A_good — strictly diagonally dominant: True
  Row margins: [2.5 3.8 5.2]

A_bad  — strictly diagonally dominant: False
  Row margins: [-4.  0. -1.]

A_ex   — strictly diagonally dominant: True,  margins: [2.7 6.6 9.5]
```

출력은 배포 노트북에 실린 출력과 같다. 손으로 계산하면 `A_ex`의 여유는 $`3 - 0.3 = 2.7`$, $`7 - 0.4 = 6.6`$, $`10 - 0.5 = 9.5`$이고, `A_good`은 $`4 - 1.5 = 2.5`$, $`5 - 1.2 = 3.8`$, $`6 - 0.8 = 5.2`$, `A_bad`는 $`1 - 5 = -4`$, $`2 - 2 = 0`$, $`1 - 2 = -1`$이다. `A_bad`의 1행은 여유가 0이어서 엄밀한 판정에서는 우위가 아니다.

노트북 4.2절의 스펙트럼 반경과 비교하면 판정의 의미가 드러난다. `A_good`은 $`\rho(T_J) = 0.2`$, $`\rho(T_{GS}) = 0.0817`$로 두 방법이 모두 수렴하고, `A_bad`는 $`\rho(T_J) = 2.4256`$, $`\rho(T_{GS}) = 7.0707`$로 모두 발산하며, 이어지는 셀에서 야코비 반복값의 노름은 10회 만에 4404.97까지 커진다. 다만 대각 우위는 충분조건일 뿐이다. 문제 6의 2차원 라플라스 행렬은 내부 행에서 $`|-4| = 1 + 1 + 1 + 1`$이어서 엄밀한 대각 우위가 아니지만, 가우스-자이델 방법이 수렴한다.

## 7. 문제 5: 과완화법(SOR)

### 7.1 풀이 방법

SOR 공식은 가우스-자이델 값 $`\tilde{x}_i`$와 이전 값의 가중 결합으로 쓸 수 있다.

```math
x_i^{(k+1)} = (1 - \omega)\, x_i^{(k)} + \omega\, \tilde{x}_i
```

배포된 코드가 가우스-자이델 값 `x_gs_i`를 이미 계산하므로, 빈칸은 이 식을 그대로 옮긴 `(1 - omega) * x_old[i] + omega * x_gs_i`이다. 성분 $`i`$를 갱신하는 시점에 `x_old[i]`와 `x[i]`는 같은 값(이번 반복에서 아직 바뀌지 않은 값)이므로 어느 쪽을 써도 된다. $`\omega = 1`$이면 갱신이 `x_gs_i` 자체가 되어 가우스-자이델 방법과 같다. 완화법은 [12장 강의 노트](../../Lecture-Notes/Ch12_Iterative-Methods/Concepts_Lecture.ko.md)의 6절에서 다룬다.

### 7.2 작성한 코드

```python
            x[i] = (1 - omega) * x_old[i] + omega * x_gs_i
```

### 7.3 실행 결과와 검증

```text
Method            Iterations
----------------------------
Jacobi                    23
GS (ω=1.0)                13
SOR ω=1.1                 11
SOR ω=1.3                 21
SOR ω=1.5                 35
SOR ω=1.7                 67
```

```text
Empirical optimal omega : 1.045  (10 iters)
Theoretical optimal omega: 1.033
GS iterations            : 13
Best SOR iterations      : 10
SOR speedup over GS      : 1.3x
```

같은 함수에 $`\omega = 1`$을 넣으면 13회 만에 수렴하여 가우스-자이델 방법과 반복 횟수와 해가 같다. 이론적 최적값은 노트북의 공식에 $`\rho(T_J) = 0.3536`$을 넣은 $`2/(1 + \sqrt{1 - 0.125}) = 1.033`$이고, 실험으로 찾은 최적값 1.045와 가깝다. $`\omega = 1.033`$으로 풀어도 10회가 걸린다. 이 시스템은 $`\rho(T_J)`$가 작아 가우스-자이델 방법만으로도 빨리 수렴하므로 최적의 $`\omega`$가 1에 가깝고, 1.3 이상의 $`\omega`$는 지나치게 나아가 오히려 반복이 늘어난다(21회, 35회, 67회).

## 8. 문제 6: 2차원 열전도의 격자 SOR

### 8.1 풀이 방법

격자를 제자리에서 훑으므로, 절점 $`(i, j)`$에서 `T_gs`를 계산할 때 위쪽과 왼쪽 이웃 `T[i-1, j]`, `T[i, j-1]`은 이번 반복에서 이미 갱신된 값이고, 아래쪽과 오른쪽 이웃 `T[i+1, j]`, `T[i, j+1]`과 절점 자신의 `T[i, j]`는 이전 반복의 값이다. 따라서 `T_gs`는 가우스-자이델 값이고, `T[i, j]`가 이전 값 역할을 하므로 문제 5와 같은 가중 결합 `(1 - omega) * T[i, j] + omega * T_gs`가 SOR 갱신이 된다. 행렬을 조립하지 않아도 5점 스텐실의 각 식이 곧 한 절점의 갱신이다.

### 8.2 작성한 코드

```python
                    T[i, j] = (1 - omega) * T[i, j] + omega * T_gs
```

### 8.3 실행 결과와 검증

```text
2D Laplace (n=30, 900 unknowns):
  Gauss-Seidel : 1267 iterations
  SOR (ω=1.7)  :  243 iterations
  SOR speedup  : 5.2x
  Max |GS - SOR|: 8.22e-05
```

노트북 6절의 다음 셀은 허용 오차 $`10^{-5}`$로 격자 크기를 바꾸어 반복 횟수를 비교한다.

```text
   n    unknowns    GS iters   SOR iters   SOR speedup
------------------------------------------------------
  10         100         157          49           3.2x
  20         400         514          91           5.6x
  30         900        1043         207           5.0x
  50        2500        2553         530           4.8x
```

이 모형 문제에서는 야코비 반복행렬의 스펙트럼 반경이 $`\rho(T_J) = \cos(\pi h)`$ $`(h = 1/(n+1))`$이다. 노트북의 최적 공식에 넣으면 $`\omega_{\text{opt}} = 2/(1 + \sin(\pi h))`$이 되어, $`n = 30`$에서 약 1.816이다. 같은 함수를 이 값으로 실행하면 110회 만에 수렴하여, $`\omega = 1.7`$의 243회와 가우스-자이델의 1267회보다 적다.

- **격자 크기에 따른 증가:** $`\rho(T_{GS}) = \cos^2(\pi h)`$는 $`n = 10, 20, 30, 50`$에서 $`0.921, 0.978, 0.990, 0.996`$으로 1에 다가가므로, 가우스-자이델의 반복 횟수가 157회에서 2553회로 빠르게 늘어난다.
- **고정된 가중 인수:** 최적값 $`2/(1 + \sin(\pi h))`$는 같은 $`n`$에서 $`1.560, 1.741, 1.816, 1.884`$이다. 고정된 $`\omega = 1.7`$은 $`n = 20`$의 최적값에 가장 가까우며, 이때 속도 비가 5.6배로 가장 크다.
- **GS와 SOR 결과의 차이:** 두 방법은 한 번의 갱신량이 $`10^{-6}`$보다 작아지면 멈추지만, 수렴이 느리면 남은 오차가 갱신량보다 훨씬 크다. 오차는 대략 갱신량의 $`\rho/(1-\rho)`$배이며, $`\rho(T_{GS}) \approx 0.990`$이면 약 97배이다. 매우 작은 허용 오차로 구한 해와 비교하면 가우스-자이델 결과의 오차는 $`9.6 \times 10^{-5}`$, SOR($`\omega = 1.7`$) 결과의 오차는 $`1.4 \times 10^{-5}`$이어서, 출력된 차이 $`8.22 \times 10^{-5}`$는 대부분 가우스-자이델 쪽에 남은 오차이다.

| 과완화법(SOR) | 가우스-자이델 값과 이전 값을 $`(1-\omega)x^{(k)} + \omega\tilde{x}`$로 섞으며, $`\omega = 1`$이면 가우스-자이델 방법이고 최적의 $`\omega`$는 $`2/(1 + \sqrt{1 - \rho(T_J)^2})`$이다. |

## 점검 문제

1. **두 종류의 L과 U:** 행렬 분할 $`A = D + L + U`$의 $`L`$과 LU 분해 $`A = LU`$의 $`L`$은 어떻게 다른가?

   <details>
   <summary>정답</summary>

   행렬 분할의 $`L`$은 $`A`$의 대각 아래 성분을 그대로 옮긴 행렬이고 대각이 0이다. LU 분해의 $`L`$은 소거 계수로 이루어진 단위 하삼각 행렬로 대각이 1이며, 일반적으로 $`A`$의 성분과 같지 않다.

   </details>

2. **나눗셈의 의미:** 문제 2의 `(b - R @ x) / d`에서 `/ d`는 행렬 연산으로 무엇에 해당하는가?

   <details>
   <summary>정답</summary>

   `d`는 대각 성분의 벡터이고 `/`는 성분별 나눗셈이므로, 벡터에 $`D^{-1}`$을 곱하는 것과 같다. 대각 행렬의 역행렬은 각 대각 성분의 역수를 대각에 둔 행렬이기 때문이다.

   </details>

3. **x와 x_old:** 문제 3에서 `sigma`의 오른쪽 부분을 `A[i, i+1:] @ x_old[i+1:]`로 바꾸면 결과가 달라지는가? 왼쪽 부분을 `x_old[:i]`로 바꾸면 어떤가?

   <details>
   <summary>정답</summary>

   오른쪽 부분은 달라지지 않는다. 성분 $`i`$를 계산하는 시점에 `x[i+1:]`은 아직 갱신되지 않아 `x_old[i+1:]`과 같기 때문이다. 왼쪽 부분을 `x_old[:i]`로 바꾸면 이번 반복의 새 값을 쓰지 않게 되어 야코비 반복법이 된다.

   </details>

4. **반복 횟수의 비:** 열 네트워크에서 야코비 반복법은 23회, 가우스-자이델 방법은 13회가 걸렸다. 이 비를 스펙트럼 반경으로 설명하라.

   <details>
   <summary>정답</summary>

   반복 횟수는 대략 $`1/(-\log\rho)`$에 비례한다. 이 삼중대각 행렬에서 $`\rho(T_J) = 0.3536`$, $`\rho(T_{GS}) = 0.125 = \rho(T_J)^2`$이므로 $`\log\rho(T_{GS}) = 2\log\rho(T_J)`$이고, 가우스-자이델은 약 절반의 반복이 필요하다. $`13/23 \approx 0.57`$이 이와 맞는다.

   </details>

5. **가중 인수의 효과:** 열 네트워크에서는 $`\omega = 1.7`$이 가우스-자이델보다 느렸지만(67회 대 13회), 2차원 격자에서는 훨씬 빨랐다(243회 대 1267회). 그 이유를 설명하라.

   <details>
   <summary>정답</summary>

   최적의 $`\omega`$는 $`2/(1 + \sqrt{1 - \rho(T_J)^2})`$로 $`\rho(T_J)`$에 따라 정해진다. 열 네트워크는 $`\rho(T_J) = 0.354`$로 작아 최적값이 1.033이므로 1.7은 지나치게 크다. $`n = 30`$인 격자는 $`\rho(T_J) = \cos(\pi/31) \approx 0.995`$로 1에 가까워 최적값이 약 1.816이고, 1.7은 이에 가까워 반복을 크게 줄인다.

   </details>

6. **허용 오차와 실제 오차:** 문제 6에서 두 방법 모두 갱신량이 $`10^{-6}`$보다 작아질 때 멈췄는데도 결과가 $`8.22 \times 10^{-5}`$만큼 다른 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   갱신량이 작다는 것은 수렴이 끝났다는 뜻이 아니다. 오차는 대략 갱신량의 $`\rho/(1-\rho)`$배로 남으며, 가우스-자이델의 $`\rho \approx 0.990`$에서는 약 97배이다. 실제로 가우스-자이델 결과의 오차는 $`9.6 \times 10^{-5}`$로, 출력된 차이의 대부분을 차지한다.

   </details>
