## 3. 문제 1: 증분 탐색

### 3.1 풀이 방법

두 실수의 곱은 부호가 서로 다를 때만 음수이므로, $`f(x_k) \cdot f(x_{k+1}) < 0`$이면 소구간의 양 끝에서 부호가 바뀐다. $`f`$가 연속이면 중간값 정리에 따라 그 소구간에 근이 적어도 하나 있다. 부등호가 엄격하므로 격자점에서 $`f`$가 정확히 0이 되는 경우는 곱이 0이어서 잡히지 않는다. 증분 탐색은 [5장 강의 노트](../../Lecture-Notes/Ch05_Roots-Bracketing-Methods/Concepts_Lecture.ko.md)의 5절에서 다룬다.

### 3.2 작성한 코드

```python
        if func(x[k]) * func(x[k+1]) < 0:
```

### 3.3 실행 결과와 검증

```text
ns= 20  ->  7 bracket(s) found
ns= 50  ->  5 bracket(s) found
ns=100  ->  9 bracket(s) found

Brackets (ns=100):
  [3.2424, 3.2727]
  [3.3636, 3.3939]
  [3.7273, 3.7576]
  [4.2121, 4.2424]
  [4.2424, 4.2727]
  [4.6970, 4.7273]
  [5.1515, 5.1818]
  [5.1818, 5.2121]
  [5.6667, 5.6970]
```

출력은 배포 노트북의 출력과 같다. $`f(x) = \sin(10x) + \cos(3x)`$를 $`[3, 6]`$에서 20만 개의 소구간으로 나누어 부호 변화를 세면 근은 9개이며, $`n_s = 100`$(간격 0.0303)은 9개를 모두 찾았다. 그런데 $`n_s = 50`$(간격 0.0612)은 $`n_s = 20`$(간격 0.158)보다 적은 5개만 찾는다. 4.21\~4.27과 5.15\~5.21처럼 두 근이 가까이 붙어 있는 곳에서 한 소구간에 근이 두 개 들어가면 양 끝의 부호가 같아져 둘 다 놓치는데, 어떤 쌍이 한 소구간에 들어갈지는 격자점의 위치에 따라 정해지기 때문이다. 따라서 찾은 구간의 수는 $`n_s`$에 대해 단조롭지 않으며, 근이 모여 있을 수 있으면 간격을 충분히 작게 잡아야 한다.

## 4. 문제 2: 이분법

### 4.1 풀이 방법

중점은 $`x_r = (x_l + x_u)/2`$이다. 이어지는 부호 판정에서 $`f(x_l) \cdot f(x_r) < 0`$이면 근이 왼쪽 절반에 있어 `xu = xr`로 두고, 그렇지 않으면 근이 오른쪽 절반 $`[x_r, x_u]`$에 있으므로 왼쪽 끝을 `xl = xr`로 옮긴다. 이분법과 그 수렴은 [5장 강의 노트](../../Lecture-Notes/Ch05_Roots-Bracketing-Methods/Concepts_Lecture.ko.md)의 6, 7절에서 다룬다.

### 4.2 작성한 코드

```python
        xr = (xl + xu) / 2  # — midpoint
        ea = abs((xr - xr_old) / xr) if xr != 0 else abs(xr - xr_old)  # approx. relative error

        if func(xl) * func(xr) < 0:     #  — sign test: root in left half?
            xu = xr
        else:
            xl = xr  #      — root in right half
```

### 4.3 실행 결과와 검증

```text
Root found : m = 142.73763308 kg
f(root)    : -5.203e-10
Rel. error : 6.525e-10
Iterations : 31
```

반복 표 31행은 배포 노트북의 출력과 같으므로 [과제 안내문](Original/Assignment.ko.md)의 문제 2를 참고한다. 결과는 다음과 같이 확인한다.

- **첫 반복:** `xr_old`가 `xl = 50`으로 시작하므로 첫 중점 150에서 $`\varepsilon_a = |150 - 50|/150 = 0.6667`$이다. 표의 첫 행과 같다.
- **반복 횟수:** 반복 $`n`$에서 중점이 움직이는 거리는 $`200/2^n`$이므로 $`\varepsilon_a \approx 200/(2^n \times 142.74)`$이다. 이 값이 $`10^{-9}`$보다 작으려면 $`n > \log_2(200/(142.74 \times 10^{-9})) = 30.38`$이어야 하므로 31회에서 멈춘다. 31회의 값 $`200/2^{31}/142.738 = 6.525 \times 10^{-10}`$도 출력과 같다.
- **오차 한계:** 31회 뒤의 참 오차는 $`200/2^{31} = 9.3 \times 10^{-8}`$ 이하여야 하며, 실제 근 142.737633108과의 차는 $`2.5 \times 10^{-8}`$이다.

> **참고:** 노트북 3.1절의 알고리즘은 $`\varepsilon_a`$에 100%를 곱하지만, 코드의 `ea`는 100을 곱하지 않은 비율이다. 따라서 `es=1e-9`는 상대 오차 $`10^{-9}`$, 백분율로는 $`10^{-7}\%`$를 뜻한다. 가위치법, 뉴턴-랩슨법, 할선법의 코드도 같은 방식을 쓴다.

## 5. 문제 3: 가위치법

### 5.1 풀이 방법

두 점 $`(x_l, f_l)`$, $`(x_u, f_u)`$를 지나는 직선 $`y = f_u + \frac{f_l - f_u}{x_l - x_u}(x - x_u)`$에서 $`y = 0`$으로 놓아 $`x`$를 풀면 노트북의 식이 된다.

$$
x_r = x_u - f_u\,\frac{x_l - x_u}{f_l - f_u}
$$

반복 첫머리에서 `fl, fu = func(xl), func(xu)`를 계산해 두므로 빈칸은 그 값을 그대로 쓴다. 가위치법과 편측성 문제는 [5장 강의 노트](../../Lecture-Notes/Ch05_Roots-Bracketing-Methods/Concepts_Lecture.ko.md)의 8절에서 다룬다.

### 5.2 작성한 코드

```python
        xr = xu - fu * (xl - xu) / (fl - fu)
```

### 5.3 실행 결과와 검증

```text
Bisection:      34 iterations,  final |error| = 3.312e-05
False Position: 42 iterations,  final |error| = 3.313e-05
```

출력은 배포 노트북의 출력과 같다. 결과는 다음과 같이 해석한다.

- **가위치법이 느린 이유:** 첫 직선의 x 절편은 205.56으로 참근 142.74보다 오른쪽에 떨어진다. $`f`$는 $`[50, 250]`$에서 증가하면서 위로 볼록하므로(이계도함수가 음수) 두 끝점을 잇는 직선이 곡선 아래에 놓이고, x 절편은 매번 근의 오른쪽에 생긴다. 그래서 처음 8번의 반복은 모두 `xu`만 바꾸고 왼쪽 끝 `xl = 50`은 그대로 고정된다. 한쪽 끝이 고정되면 구간이 근 쪽으로 천천히 좁혀져 이분법보다 반복이 많아진다. 이것이 노트북 4.2절이 말한 편측성이다.
- **두 방법의 최종 오차가 같은 이유:** 오차의 기준값 `m_true = 142.7376`은 실제 근 142.737633108을 소수 넷째 자리에서 반올림한 값이다. 둘의 차가 $`3.31 \times 10^{-5}`$이므로, 두 방법의 최종 오차는 수렴의 정확도가 아니라 기준값의 반올림 오차를 보여 준다.

## 6. 문제 4: 뉴턴-랩슨법

### 6.1 풀이 방법

$`x_i`$에서의 접선 $`y = f(x_i) + f'(x_i)(x - x_i)`$에서 $`y = 0`$으로 놓으면 $`x_{i+1} = x_i - f(x_i)/f'(x_i)`$이다. 반복 첫머리에서 `fxi = f(xi)`, `fpxi = fp(xi)`를 계산하고 `fpxi`가 0에 가까운지도 확인해 두므로, 빈칸은 두 값으로 갱신 식만 쓴다. 뉴턴-랩슨법과 이차 수렴은 [6장 강의 노트](../../Lecture-Notes/Ch06_Roots-Open-Methods/Concepts_Lecture.ko.md)의 5절에서 다룬다.

### 6.2 작성한 코드

```python
        x1 = xi - fxi / fpxi  # — Newton-Raphson update
```

### 6.3 실행 결과와 검증

```text
Root found : 0.567143290409784
True root  : 0.567143290409784
|error|    : 1.110e-16
Iterations : 5

 Iter                  xi           f(xi)              ea
----------------------------------------------------------
    1      0.500000000000   -1.065307e-01    1.000000e+00
    2      0.566311003197   -1.304510e-03    1.170929e-01
    3      0.567143165035   -1.964805e-07    1.467287e-03
    4      0.567143290410   -4.440892e-15    2.210639e-07
    5      0.567143290410    1.110223e-16    5.089684e-15
```

출력은 배포 노트북의 출력과 같다. 첫 반복은 손으로 확인할 수 있다. $`x_0 = 0`$에서 $`f(0) = -1`$, $`f'(0) = 2`$이므로 $`x_1 = 0 - (-1)/2 = 0.5`$이고, $`f(0.5) = 0.5 - e^{-0.5} = -0.10653`$이다.

참 오차는 $`6.7 \times 10^{-2}`$, $`8.3 \times 10^{-4}`$, $`1.3 \times 10^{-7}`$, $`2.8 \times 10^{-15}`$로 줄어 맞는 자릿수가 반복마다 약 두 배가 된다. 이차 수렴 식 $`e_{i+1} \approx \frac{|f''(x^*)|}{2|f'(x^*)|} e_i^2`$의 계수는 $`f''(x^*) = -e^{-x^*} = -0.5671`$, $`f'(x^*) = 1 + e^{-x^*} = 1.5671`$에서 $`0.181`$이다. 실제 비 $`e_{i+1}/e_i^2`$은 $`0.185`$, $`0.181`$로 이 계수와 일치한다.

## 7. 문제 5: 할선법

### 7.1 풀이 방법

뉴턴-랩슨 식의 $`f'(x_1)`$을 두 점 $`(x_0, f_0)`$, $`(x_1, f_1)`$을 지나는 할선의 기울기 $`(f_0 - f_1)/(x_0 - x_1)`$로 바꾸면 다음 식이 된다.

$$
x_2 = x_1 - f_1\,\frac{x_0 - x_1}{f_0 - f_1}
$$

가위치법의 식과 모양이 같지만, 할선법은 부호 판정 없이 가장 최근의 두 점을 쓰므로 두 점이 근을 감쌀 필요가 없다. 반복 끝의 `x0, x1 = x1, x2`가 점을 한 칸씩 옮긴다. 할선법은 [6장 강의 노트](../../Lecture-Notes/Ch06_Roots-Open-Methods/Concepts_Lecture.ko.md)의 6절에서 다룬다.

### 7.2 작성한 코드

```python
        x2 = x1 - f1 * (x0 - x1) / (f0 - f1)
```

### 7.3 실행 결과와 검증

```text
=== f(x) = x - e^{-x},  true root = 0.5671432904097838 ===
Newton-Raphson:  5 iters,  |error| = 1.110e-16
Secant:          6 iters,  |error| = 0.000e+00
```

출력은 배포 노트북의 출력과 같다. 첫 반복은 $`x_0 = 0`$, $`x_1 = 1`$에서 $`f_0 = -1`$, $`f_1 = 1 - e^{-1} = 0.63212`$이므로 $`x_2 = 1 - 0.63212 \times (0 - 1)/(-1 - 0.63212) = 0.61270`$이다. 이후 참 오차는 $`4.6 \times 10^{-2}`$, $`3.3 \times 10^{-3}`$, $`2.7 \times 10^{-5}`$, $`1.6 \times 10^{-8}`$, $`7.9 \times 10^{-14}`$, 0으로 줄어, 오차의 로그가 반복마다 약 1.6~1.7배가 되는 초선형 수렴을 보인다. 뉴턴-랩슨법보다 한 번 더 반복했지만 도함수가 필요하지 않다.

노트북 7절은 완성한 네 함수를 번지 점프 선수 문제에서 허용 오차 $`10^{-8}`$로 비교한다.

## 점검 문제

1. **놓친 근:** 문제 1에서 $`n_s = 50`$이 $`n_s = 20`$보다 적은 구간을 찾은 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   가까이 붙은 두 근이 한 소구간에 함께 들어가면 양 끝에서 함숫값의 부호가 같아져 두 근을 모두 놓친다. 어떤 근의 쌍이 한 소구간에 들어갈지는 격자점의 위치에 달려 있으므로, 간격이 더 작은 $`n_s = 50`$에서 오히려 더 많은 쌍이 묶일 수 있다.

   </details>

2. **이분법의 반복 횟수:** 문제 2의 구간 $`[50, 250]`$에서 절대 오차 $`10^{-6}`$을 보장하려면 몇 번 반복해야 하는가?

   <details>
   <summary>정답</summary>

   $`200/2^n \le 10^{-6}`$에서 $`n \ge \log_2(2 \times 10^8) = 27.6`$이므로 28번이다. 노트북의 이어지는 셀도 28을 출력한다.

   </details>

3. **편측성:** 문제 3에서 $`f`$가 아래로 볼록한 증가 함수였다면 가위치법에서 어느 끝점이 고정되는가?

   <details>
   <summary>정답</summary>

   아래로 볼록하면 두 끝점을 잇는 직선이 곡선 위에 놓여 x 절편이 매번 근의 왼쪽에 생긴다. 그러면 `xl`만 바뀌고 오른쪽 끝 `xu`가 고정된다.

   </details>

4. **이차 수렴의 확인:** 문제 4에서 $`e_2 = 8.3 \times 10^{-4}`$일 때 이차 수렴 계수 0.181을 써서 $`e_3`$을 예측하고 실제 값과 비교하라.

   <details>
   <summary>정답</summary>

   $`e_3 \approx 0.181 \times (8.3 \times 10^{-4})^2 = 1.25 \times 10^{-7}`$이다. 실제 오차 $`|0.567143165035 - 0.567143290410| = 1.25 \times 10^{-7}`$과 일치한다.

   </details>

5. **할선법과 가위치법:** 두 방법의 갱신 식은 같은 꼴인데 할선법이 더 빠르게 수렴하는 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   가위치법은 근을 감싸도록 부호 판정으로 끝점을 고르기 때문에 오래된 끝점이 고정될 수 있다. 할선법은 항상 가장 최근의 두 점을 쓰므로 할선이 근 근처의 접선에 빠르게 가까워지고, 그 결과 초선형으로 수렴한다. 대신 근을 감싼다는 보장이 없어 발산할 수 있다.

   </details>
