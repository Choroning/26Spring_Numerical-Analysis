## 3. 문제 1: 황금 분할 탐색

### 3.1 풀이 방법

$`f(x_1) < f(x_2)`$이면 새 구간은 $`[x_2, x_u]`$이고, 코드는 이미 `xl = x2`, `x2 = x1`로 왼쪽 끝과 왼쪽 내부 점을 옮겨 두었다. 남은 일은 갱신된 구간에서 새 오른쪽 내부 점 $`x_1 = x_l + (\varphi - 1)(x_u - x_l)`$을 구하는 것이다. 반대 분기에서는 새 구간 $`[x_l, x_1]`$에서 새 왼쪽 내부 점 $`x_2 = x_u - (\varphi - 1)(x_u - x_l)`$을 구한다. 두 식 모두 이미 바뀐 `xl` 또는 `xu`를 써야 한다.

이전 내부 점을 그대로 재사용할 수 있는 것은 $`r = \varphi - 1 \approx 0.618`$이 $`r^2 = 1 - r`$을 만족하기 때문이다. 예를 들어 $`[x_l, x_u]`$에서 $`[x_l, x_1]`$로 줄이면 새 폭은 $`rL`$($`L = x_u - x_l`$)이고, 새 오른쪽 내부 점은 $`x_l + r \cdot rL = x_l + (1 - r)L = x_u - rL`$로 이전의 $`x_2`$와 정확히 같다. 그래서 반복마다 함수를 한 번만 계산한다. 황금 분할 탐색은 [7장 강의 노트](../../Lecture-Notes/Ch07_Optimization/Concepts_Lecture.ko.md)의 6절에서 다룬다.

### 3.2 작성한 코드

```python
            x1 = xl + (phi - 1) * (xu - xl)     # — new right interior point
```

```python
            x2 = xu - (phi - 1) * (xu - xl)     # — new left interior point
```

### 3.3 실행 결과와 검증

```text
Minimum found : x* = 1.4275517674
f(x*)         : -1.7757256531
True minimum  : 1.4275517797
|error|       : 1.229e-08
Iterations    : 45
```

반복 표는 배포 노트북의 출력과 같으므로 [과제 안내문](Original/Assignment.ko.md)의 문제 1을 참고한다. 결과는 다음과 같이 확인한다.

- **첫 단계:** $`[0, 4]`$에서 $`d = 0.618 \times 4 = 2.4721`$이므로 $`x_1 = 2.4721`$, $`x_2 = 1.5279`$이다. $`f(x_1) = -0.630 \geq f(x_2) = -1.765`$이므로 새 구간은 $`[0, 2.4721]`$이고, 표의 첫 행의 구간 폭 2.472136과 같다. 새 오른쪽 내부 점은 $`0 + 0.618 \times 2.4721 = 1.5279`$로 이전 $`x_2`$와 같다.
- **반복 횟수:** 반복 $`i`$의 `xint`는 $`4 \times 0.618^{i-1}`$이므로 $`\varepsilon_a = 0.382 \times 4 \times 0.618^{i-1} / 1.4276`$이다. 이 식은 반복 40의 $`7.568 \times 10^{-9}`$, 반복 43의 $`1.787 \times 10^{-9}`$을 그대로 재현하고, 반복 45에서 $`6.8 \times 10^{-10} < 10^{-9}`$이 되어 멈춘다.
- **오차가 $`10^{-8}`$ 근처에서 멈추는 이유:** 최솟값 근처에서는 $`f(x) - f(x^*) \approx \frac{1}{2}f''(x^*)(x - x^*)^2`$이므로, 이 차가 $`f`$ 값의 반올림 오차 $`\varepsilon_{\text{mach}}|f(x^*)|`$보다 작으면 두 점의 함숫값을 구별할 수 없다. $`f''(x^*) = 0.2 + 2\sin(x^*) = 2.18`$, $`|f(x^*)| = 1.776`$을 넣으면 구별할 수 있는 한계는 $`|x - x^*| \approx \sqrt{2\varepsilon_{\text{mach}}|f^*|/f''} \approx 1.9 \times 10^{-8}`$이고, 실제 오차 $`1.229 \times 10^{-8}`$은 이 한계와 같은 크기이다. 이어지는 셀에서 허용 오차를 $`10^{-10}`$으로 줄여 49회 반복해도 오차가 그대로인 것도 같은 이유이다.

- **9번째 반복:** 기록된 추정값은 8개인데 반복 횟수는 9로 나온다. 9번째 반복에서 세 점의 함숫값이 부동 소수점으로 같아져 `den`이 정확히 0이 되었고, 함수가 분모 확인에서 멈춘 뒤 8번째 추정값을 돌려주었기 때문이다. 오차가 $`10^{-9}`$ 근처에서 더 줄지 않는 것도 3.3절과 같은 반올림의 한계이다.

## 5. 문제 3: 최급 하강법

### 5.1 풀이 방법

알고리즘의 3단계 $`\mathbf{x}^{(k+1)} = \mathbf{x}^{(k)} - \alpha^{(k)} \mathbf{g}^{(k)}`$를 그대로 옮긴다. 바로 위 줄에서 `backtrack_linesearch`가 $`f(\mathbf{x} - \alpha\mathbf{g}) < f(\mathbf{x})`$가 될 때까지 $`\alpha`$를 절반씩 줄여 정해 두므로, 빈칸은 그 $`\alpha`$로 기울기의 반대 방향으로 움직이기만 하면 된다. `x`와 `g`는 NumPy 배열이므로 한 줄로 두 좌표를 함께 갱신한다. 최급 하강법은 [7장 강의 노트](../../Lecture-Notes/Ch07_Optimization/Concepts_Lecture.ko.md)의 10절에서 다룬다.

### 5.2 작성한 코드

```python
        x = x - alpha * g                       # x - alpha * g  # — steepest descent step
```

### 5.3 실행 결과와 검증

```text
Starting point    : [-2.  3.]
Minimizer found   : [-1.00000001  1.50000001]
True minimum      : [-1.   1.5]
f(minimizer)      : 0.7500000000
f(true min)       : 0.7500000000
|error|           : 2.107e-08
Iterations        : 200
```

출력은 배포 노트북의 출력과 같다. 최솟값 $`(-1, 1.5)`$와의 거리는 $`2.1 \times 10^{-8}`$이지만 반복은 최대 횟수 200까지 갔다. 완성한 함수로 반복 기록을 살펴보면 그 원인을 알 수 있다.

- 기울기 노름은 반복 10에서 $`3.1 \times 10^{-2}`$, 반복 30에서 $`3.1 \times 10^{-5}`$, 반복 48에서 $`6.0 \times 10^{-8}`$으로 줄다가, 반복 50부터 $`2.98 \times 10^{-8}`$에 멈춘다. 이 값은 허용 오차 $`10^{-8}`$보다 커서 중지 조건이 만족되지 않는다.
- 반복 50 이후에는 $`f(\mathbf{x}) - 0.75`$가 부동 소수점으로 0이 되어 $`f(\mathbf{x} - \alpha\mathbf{g}) < f(\mathbf{x})`$를 만족하는 $`\alpha`$가 없다. 선 탐색은 50번 절반으로 줄인 $`\alpha = 0.5^{50} = 8.9 \times 10^{-16}`$을 돌려주고, 점은 거의 움직이지 않는다.

즉 함숫값의 차로 감소를 판정하는 백트래킹은 $`f`$ 값의 반올림 오차보다 작은 개선을 볼 수 없으므로, 기울기 노름의 허용 오차를 이 한계보다 작게 잡으면 반복이 끝나지 않는다. 노트북의 기울기 노름 그래프가 반복 50 부근부터 수평인 것이 이 현상이다.

### 6.2 연습 B: 고정 스텝 크기의 최급 하강법

힌트대로 선 탐색을 상수로 바꾸되, `steepest_descent` 안의 코드를 고치지 않도록 이름 `backtrack_linesearch`를 상수를 돌려주는 함수로 잠시 바꿔 놓고 호출한다.

```python
# Written for this explanation: the completed notebook leaves this cell empty.
backtrack_original = backtrack_linesearch
x0 = np.array([-2.0, 3.0])
for alpha_fixed in [0.01, 0.1, 0.5]:
    backtrack_linesearch = lambda f, x, grad, a=alpha_fixed: a   # constant step instead of backtracking
    xk, fk, nk, hk = steepest_descent(f2d, grad_f2d, x0, tol=1e-8, maxit=200)
    print(f'alpha = {alpha_fixed:<4}  iterations = {nk:>3}  '
          f'||grad|| = {np.linalg.norm(grad_f2d(xk)):.3e}  |x - x*| = {np.linalg.norm(xk - x2_true):.3e}')
backtrack_linesearch = backtrack_original
```

```text

alpha = 0.1   iterations = 200  ||grad|| = 1.723e-07  |x - x*| = 2.255e-07
alpha = 0.5   iterations = 200  ||grad|| = 2.038e+41  |x - x*| = 3.893e+40
```

$`f`$는 이차 함수이고 헤세 행렬은 $`H = \begin{bmatrix} 4 & 2 \\ 2 & 2 \end{bmatrix}`$이므로, 고정 스텝 크기에서는 오차가 반복마다 $`I - \alpha H`$를 곱한 만큼 변한다. $`H`$의 고유값은 $`3 \pm \sqrt{5}`$, 곧 0.764와 5.236이므로 오차의 감소 비율은 $`\max_i |1 - \alpha\lambda_i|`$이다.

| $`\alpha`$ | $`\max_i \vert 1 - \alpha\lambda_i \vert`$ | 결과 |
|:-----|:-----|:-----|
| 0.01 | 0.992 | 수렴하지만 200회 뒤에도 $`\lVert\mathbf{x} - \mathbf{x}^*\rVert = 0.39`$로 느리다 |
| 0.1 | 0.924 | 200회 뒤 $`2.3 \times 10^{-7}`$까지 수렴한다 |
| 0.5 | 1.618 | 비율이 1보다 커서 발산한다 |

*표 2. 고정 스텝 크기에 따른 오차의 감소 비율*

고정 스텝 크기는 $`\alpha < 2/\lambda_{\max} = 0.382`$일 때만 수렴한다. 너무 작으면 느리고 너무 크면 발산하므로, 백트래킹처럼 반복마다 스텝 크기를 정하는 선 탐색이 필요하다.

## 점검 문제

1. **갱신 순서:** 문제 1의 $`f(x_1) < f(x_2)`$ 분기에서 `x1 = xl + (phi - 1) * (xu - xl)`을 `xl = x2`보다 먼저 계산하면 어떻게 되는가?

   <details>
   <summary>정답</summary>

   이전 구간 $`[x_l, x_u]`$에서 계산되므로 새 `x1`이 이전 $`x_1`$, 곧 새 `x2`와 같은 점이 되어 두 내부 점이 겹친다. 그러면 다음 반복의 비교가 의미를 잃고 구간과 내부 점의 비율이 깨져, 재사용 성질과 수렴 속도 0.618이 성립하지 않는다.

   </details>

2. **황금비의 성질:** $`r = \varphi - 1`$이 $`r^2 = 1 - r`$을 만족함을 $`\varphi = (1 + \sqrt{5})/2`$로 확인하라.

   <details>
   <summary>정답</summary>

   $`r = (\sqrt{5} - 1)/2`$이므로 $`r^2 = (6 - 2\sqrt{5})/4 = (3 - \sqrt{5})/2`$이고, $`1 - r = (2 - \sqrt{5} + 1)/2 = (3 - \sqrt{5})/2`$이다. 두 값이 같다.

   </details>

3. **포물선 보간의 위험:** 세 점이 거의 한 직선 위에 있으면 포물선 보간에 어떤 문제가 생기는가?

   <details>
   <summary>정답</summary>

   분모 `den`이 0에 가까워져 꼭짓점이 매우 멀리 튀거나 계산할 수 없다. 직선에 가까운 포물선은 곡률이 거의 없어 꼭짓점이 정해지지 않기 때문이다. 노트북의 함수는 `abs(den) < 1e-30`이면 반복을 멈춘다.

   </details>

4. **멈추지 않는 반복:** 문제 3에서 허용 오차를 `tol=1e-6`으로 두었다면 반복은 몇 번 근처에서 끝나겠는가?

   <details>
   <summary>정답</summary>

   기울기 노름은 반복 30에서 $`3.1 \times 10^{-5}`$이었고 반복마다 약 0.7배씩 줄었으므로, $`10^{-6}`$ 아래로는 반복 40 근처에서 내려간다. 이는 반올림 한계에 이르는 반복 50보다 앞이므로 최대 횟수까지 가지 않고 정상적으로 멈춘다. 실제로 실행하면 40회에서 멈춘다.

   </details>

5. **고정 스텝 크기의 상한:** 연습 B의 함수에서 $`\alpha = 0.3`$이면 수렴하는가?

   <details>
   <summary>정답</summary>

   $`|1 - 0.3 \times 0.764| = 0.771`$, $`|1 - 0.3 \times 5.236| = 0.571`$이므로 감소 비율은 0.771로 1보다 작아 수렴한다. 0.3이 상한 $`2/\lambda_{\max} = 0.382`$보다 작기 때문이다.

   </details>
