## 3. 문제 1: Doolittle 알고리즘

### 3.1 풀이 방법

공식의 합 $`\sum_{m=0}^{k-1} \ell_{km} u_{mj}`$는 $`L`$의 $`k`$행 앞부분과 $`U`$의 $`j`$열 윗부분의 내적이므로 `L[k, :k] @ U[:k, j]`로 쓴다. 마찬가지로 $`\sum_{m=0}^{k-1} \ell_{im} u_{mk}`$는 `L[i, :k] @ U[:k, k]`이다. $`k = 0`$이면 두 슬라이스가 비어 있고, 길이 0인 배열의 내적은 0이므로 $`u_{0j} = a_{0j}`$, $`\ell_{i0} = a_{i0}/u_{00}`$이 별도 처리 없이 성립한다.

계산 순서도 중요하다. $`U`$의 $`k`$행은 $`L`$의 $`k`$행 앞부분(이전 단계에서 구한 열)만 쓰고, $`L`$의 $`k`$열은 방금 구한 $`u_{kk}`$로 나누므로, 단계마다 $`U`$의 행을 먼저 구하고 $`L`$의 열을 나중에 구한다. LU 분해의 구조와 소거 계수의 관계는 [10장 강의 노트](../../Lecture-Notes/Ch10_LU-Factorization/Concepts_Lecture.ko.md)의 1, 2절과 [10장 실습 노트](../../Lecture-Notes/Ch10_LU-Factorization/Concepts_Lab.ko.md)의 1절에서 다룬다.

### 3.2 작성한 코드

```python
            U[k, j] = A[k, j] - L[k, :k] @ U[:k, j]
```

```python
            L[i, k] = (A[i, k] - L[i, :k] @ U[:k, k]) / U[k, k]
```

### 3.3 실행 결과와 검증

```text
L =
 [[1.         0.         0.        ]
 [0.25       1.         0.        ]
 [0.5        0.66666667 1.        ]]
U =
 [[ 8.          7.          9.        ]
 [ 0.         -0.75       -1.25      ]
 [ 0.          0.         -0.66666667]]
LU =
 [[8. 7. 9.]
 [2. 1. 1.]
 [4. 3. 3.]]
L_sc =
 [[1.         0.         0.        ]
 [0.25       1.         0.        ]
 [0.5        0.66666667 1.        ]]
U_sc =
 [[ 8.          7.          9.        ]
 [ 0.         -0.75       -1.25      ]
 [ 0.          0.         -0.66666667]]
L_scU_sc =
 [[8. 7. 9.]
 [2. 1. 1.]
 [4. 3. 3.]]
```

손으로 계산하면 $`U`$의 0행은 $`[8, 7, 9]`$, $`\ell_{10} = 2/8 = 0.25`$, $`\ell_{20} = 4/8 = 0.5`$이고, $`u_{11} = 1 - 0.25 \cdot 7 = -0.75`$, $`u_{12} = 1 - 0.25 \cdot 9 = -1.25`$, $`\ell_{21} = (3 - 0.5 \cdot 7)/(-0.75) = 2/3`$, $`u_{22} = 3 - 0.5 \cdot 9 - (2/3)(-1.25) = -2/3`$으로 출력과 같으며, `L @ U`가 시험 행렬을 재현한다.

시험 행렬 `A_test`는 셀의 주석과 달리 노트북 1.2절의 예제 $`A`$의 행 순서를 바꾼 것이다. 이 순서에서는 0열의 첫 성분 8이 가장 크고, 소거 뒤 1열의 아래쪽 값 $`-0.75`$와 $`-0.5`$ 가운데서도 위쪽 값의 절댓값이 크므로, 부분 피봇팅을 하는 `sc.linalg.lu`도 행을 바꾸지 않아 $`P = I`$가 되고 두 결과가 같아진다. 1.2절의 원래 순서로 함수를 실행하면 노트북이 손으로 구한 $`L`$과 $`U`$가 나오고, 같은 행렬에 `sc.linalg.lu`를 적용하면 8이 있는 행을 맨 위로 올리는 $`P \neq I`$와 함께 위의 $`L`$, $`U`$가 나온다.

## 4. 문제 2: L과 U를 이용한 풀이

### 4.1 풀이 방법

전진 대입의 합 $`\sum_{j=0}^{i-1} \ell_{ij} d_j`$는 `L[i, :i] @ d[:i]`이다. `forward_sub`는 독스트링대로 대각 성분이 1인 단위 하삼각 행렬을 가정하므로 $`\ell_{ii}`$로 나누지 않는다. 후진 대입의 합 $`\sum_{j=i+1}^{n-1} u_{ij} x_j`$는 `U[i, i+1:] @ x[i+1:]`이고, $`U`$의 대각 성분은 1이 아니므로 `U[i, i]`로 나눈다.

`lu_solve`가 쓰는 `sc.linalg.lu`는 $`A = PLU`$를 만족하는 $`P`$를 돌려준다. 그러면 $`A\mathbf{x} = \mathbf{b}`$는 $`LU\mathbf{x} = P^{-1}\mathbf{b} = P^T\mathbf{b}`$가 되므로, 우변을 `P.T @ b`로 바꾼 뒤 두 함수를 차례로 적용한다. 전진 대입과 후진 대입은 [10장 강의 노트](../../Lecture-Notes/Ch10_LU-Factorization/Concepts_Lecture.ko.md)의 4, 5, 8절과 [10장 실습 노트](../../Lecture-Notes/Ch10_LU-Factorization/Concepts_Lab.ko.md)의 2절에서 다룬다.

### 4.2 작성한 코드

```python
        d[i] = b[i] - L[i, :i] @ d[:i]
```

```python
        x[i] = (d[i] - U[i, i+1:] @ x[i+1:]) / U[i, i]
```

### 4.3 실행 결과와 검증

```text
Solution via LU solve : [ 3.  -2.5  7. ]
Solution via np.linalg: [ 3.  -2.5  7. ]
Max difference        : 8.881784197001252e-16
Residual ||Ax - b||   : 1.4210854715202004e-14
```

해 $`(3, -2.5, 7)`$을 첫 식에 대입하면 $`3 \cdot 3 - 0.1(-2.5) - 0.2 \cdot 7 = 7.85`$로 우변과 같다. `np.linalg.solve`와의 차이 $`8.9 \times 10^{-16}`$은 해의 크기(최대 7)에 비해 머신 엡실론 수준이다.

노트북 1.5절의 열저항 네트워크도 `lu_solve`로 풀린다. 완성한 노트북은 $`T_2 = 100`$°C, $`T_3 = 50`$°C를 출력하며, $`1.75 \cdot 100 - 0.5 \cdot 50 = 150`$, $`-0.5 \cdot 100 + 2 \cdot 50 = 50`$으로 두 식이 성립한다.

> **참고:** 같은 셀은 마지막에 `Energy balance at node 2 (should = 0): 100.000000 W`를 출력한다. 계산식은 `Q2 + q12_out + q23_out + q20_out`인데, 절점 2에서 나가는 열은 $`0 + 25 + 25 = 50`$ W로 공급 열 $`Q_2 = 50`$ W와 같으므로 에너지 균형은 성립한다. 0이 되는 것은 나가는 열에서 $`Q_2`$를 뺀 값이며, 출력식이 $`Q_2`$를 더하고 있어 균형일 때 $`2Q_2 = 100`$ W가 출력된다.

## 5. 문제 3: 다중 하중 케이스의 질량-스프링 시스템

### 5.1 풀이 방법

`sc.linalg.lu_factor`는 $`L`$과 $`U`$를 한 행렬에 압축해 담고 피봇 정보를 함께 돌려준다. 이 결과 `lu_K`를 `sc.linalg.lu_solve`에 넘기면 분해를 다시 하지 않고 전진 대입과 후진 대입만으로 해를 구한다. 따라서 세 하중 케이스는 같은 `lu_K`에 우변만 바꾸어 세 번 푼다. 다중 우변에 대한 LU 분해의 이점은 [10장 실습 노트](../../Lecture-Notes/Ch10_LU-Factorization/Concepts_Lab.ko.md)의 4절에서 다룬다.

### 5.2 작성한 코드

```python
x_gravity  = sc.linalg.lu_solve(lu_K, F_gravity)
x_wind     = sc.linalg.lu_solve(lu_K, F_wind)
x_combined = sc.linalg.lu_solve(lu_K, F_combined)
```

### 5.3 실행 결과와 검증

```text
Load Case         x1 (m)      x2 (m)      x3 (m)
------------------------------------------------
Gravity          0.52000     0.88000     0.92000
Wind             1.46000     1.74000     1.16000
Combined         1.98000     2.62000     2.08000

Superposition check ||x_comb - (x_grav + x_wind)||: 4.97e-16
```

출력은 배포 노트북에 실린 출력과 같다. 중력 하중의 변위를 대입하면 $`70(0.52) - 30(0.88) = 10`$, $`-30(0.52) + 50(0.88) - 20(0.92) = 10`$, $`-20(0.88) + 30(0.92) = 10`$으로 우변 $`[10, 10, 10]`$과 같다. 시스템이 선형이므로 $`K(\mathbf{x}_g + \mathbf{x}_w) = \mathbf{F}_g + \mathbf{F}_w`$이고, 결합 하중의 해는 두 해의 합이어야 한다(중첩 원리). 차이 $`4.97 \times 10^{-16}`$은 반올림 오차 수준이다.

노트북 2.1절의 셀은 우변의 개수 $`m`$에 따라 시스템마다 `np.linalg.solve`를 부르는 방법과 한 번 분해한 뒤 `lu_solve`를 부르는 방법의 시간을 비교한다. 완성한 노트북에서 속도 차이는 $`m = 1`$의 0.9배에서 $`m = 100`$의 6.0배로 커진다. 우변이 많을수록 한 번의 분해 비용이 여러 풀이에 나뉘기 때문이다.

## 6. 문제 4: Cholesky 분해를 이용한 풀이

### 6.1 풀이 방법

$`A = LL^T`$이면 $`A\mathbf{x} = \mathbf{b}`$는 $`L\mathbf{d} = \mathbf{b}`$와 $`L^T\mathbf{x} = \mathbf{d}`$의 두 삼각 시스템이 된다. 빈칸 위의 주석은 첫 시스템에 노트북 1절에서 정의한 `forward_sub`를 쓰고 둘째 시스템에서는 $`L^T`$가 상삼각 행렬임에 주목하라고 지시하며, 작성한 코드는 이에 따라 `forward_sub(L, b)`와 `backward_sub(L.T, d)`를 쓴다. Cholesky 분해는 [10장 강의 노트](../../Lecture-Notes/Ch10_LU-Factorization/Concepts_Lecture.ko.md)의 9절과 [10장 실습 노트](../../Lecture-Notes/Ch10_LU-Factorization/Concepts_Lab.ko.md)의 5절에서 다룬다.

### 6.2 작성한 코드

```python
    d = forward_sub(L, b)
```

```python
    x = backward_sub(L.T, d)
```

### 6.3 실행 결과와 검증

```text

  x1 = 222949.7266 mm
  x2 = 445899.4532 mm
  x3 = 668849.1799 mm
  x4 = 886025.4038 mm

Max error vs np.linalg.solve: 885.4754037844386

Solve time (n=500):  Cholesky = 0.0063s,  LU = 0.0012s,  speedup = 0.2x
```

변위가 수백 m에 이르고 `np.linalg.solve`와의 최대 차이가 885 m이므로 이 결과는 틀렸다. 정확한 변위는 $`[150, 300, 450, 550]`$ mm이며, $`10^4 (2 \cdot 0.15 - 0.3) = 0`$, $`10^4(-0.3 + 0.9 - 0.55) = 500`$처럼 각 식에 대입해 확인할 수 있다.

원인은 `forward_sub`의 가정에 있다. 문제 2의 `forward_sub`는 독스트링에 적힌 대로 대각 성분이 1인 단위 하삼각 행렬을 가정하여 `d[i] = b[i] - L[i, :i] @ d[:i]`로 끝나고 $`\ell_{ii}`$로 나누지 않는다. LU 분해의 $`L`$은 이 가정을 만족하지만, Cholesky 인수 $`L`$의 대각 성분은 이 행렬에서 $`141.42, 122.47, 115.47, 50`$이어서 1이 아니다. 따라서 첫 단계의 $`\mathbf{d}`$가 틀리고, 그 뒤의 후진 대입은 올바르게 동작해도 결과가 틀린다. `backward_sub`는 `U[i, i]`로 나누므로 대각 성분이 1이 아닌 $`L^T`$에 그대로 쓸 수 있다.

> **참고:** 빈칸 위의 주석이 지시한 대로 노트북 1절의 `forward_sub`를 써서 `forward_sub(L, b)`로 풀면 Cholesky 인수에서는 성립하지 않는다. 대각 성분으로 나누는 전진 대입을 쓰면 정확한 변위 $`[150, 300, 450, 550]`$ mm가 나오고, `np.linalg.solve`와의 차이는 $`3.3 \times 10^{-16}`$ m이다. 아래는 그렇게 고친 구현이며, 제출한 노트북의 코드가 아니다.

```python
def forward_sub_general(L, b):
    """Solve L d = b for a lower triangular L with any nonzero diagonal."""
    n = len(b)
    d = np.zeros(n)
    for i in range(n):
        d[i] = (b[i] - L[i, :i] @ d[:i]) / L[i, i]
    return d
```

빈칸 한 줄만 바꾼다면 `d = sc.linalg.solve_triangular(L, b, lower=True)`처럼 일반 하삼각 시스템을 푸는 SciPy 함수를 써도 같은 결과를 얻는다.

마지막 줄의 시간 비교에서는 SPD 전용 풀이가 오히려 느리게 측정되었다. 한 번의 측정은 함수 호출 부담과 실행 환경의 영향을 크게 받으므로, 이 결과로 Cholesky 분해의 이론적 비용 이점(약 $`n^3/6`$ 대 $`n^3/3`$)을 판단하기는 어렵다.

## 7. 문제 5: LU 분해를 이용한 역행렬

### 7.1 풀이 방법

`I[:, j]`는 단위 행렬의 $`j`$번째 열 $`\mathbf{e}_j`$이므로, 반복문 밖에서 한 번 만든 `lu_obj`로 `sc.linalg.lu_solve(lu_obj, I[:, j])`를 풀면 $`A\mathbf{x}_j = \mathbf{e}_j`$의 해, 곧 $`A^{-1}`$의 $`j`$번째 열을 얻는다. 이를 `A_inv[:, j]`에 저장한다. 분해는 $`O(n^3)`$, 열마다의 풀이는 $`O(n^2)`$이다. LU 분해를 이용한 역행렬은 [11장 강의 노트](../../Lecture-Notes/Ch11_Matrix-Inverse-and-Condition/Concepts_Lecture.ko.md)의 2절과 [11장 실습 노트](../../Lecture-Notes/Ch11_Matrix-Inverse-and-Condition/Concepts_Lab.ko.md)의 1절에서 다룬다.

### 7.2 작성한 코드

```python
        A_inv[:, j] = sc.linalg.lu_solve(lu_obj, I[:, j])
```

### 7.3 실행 결과와 검증


$`AA^{-1} - I`$의 최대 성분이 $`2.2 \times 10^{-16}`$으로 머신 엡실론 수준이므로 역행렬이 맞다. `np.linalg.inv`와의 차이가 정확히 0인 것은 `np.linalg.inv`도 부분 피봇팅 LU 분해로 $`AX = I`$를 푸는 LAPACK 루틴을 쓰기 때문으로 볼 수 있다. 특이 행렬은 2행이 1행의 2배여서 행렬식이 0이고, 역행렬을 구하려 하면 `LinAlgError`가 난다.

## 8. 문제 6: 악조건 시스템의 진단

### 8.1 풀이 방법

빈칸 사이의 번호 매긴 주석이 지시하는 순서대로 `np.linalg.cond`로 2-노름 조건수를 구하고, 경험 규칙 "$`\kappa \approx 10^k`$이면 약 $`k`$자리를 잃는다"에 따라 $`\log_{10}\kappa`$의 정수 부분을 잃는 유효 숫자의 개수로 삼은 뒤, `np.linalg.solve`로 해를 구한다. 조건수와 오차 한계는 [11장 강의 노트](../../Lecture-Notes/Ch11_Matrix-Inverse-and-Condition/Concepts_Lecture.ko.md)의 7~9절과 [11장 실습 노트](../../Lecture-Notes/Ch11_Matrix-Inverse-and-Condition/Concepts_Lab.ko.md)의 2절에서 다룬다.

### 8.2 작성한 코드

```python
kappa = np.linalg.cond(K_susp)
```

```python
digits_lost = int(np.log10(kappa))
```

```python
x_susp = np.linalg.solve(K_susp, f_susp)
```

### 8.3 실행 결과와 검증

```text
Condition number kappa = 2.00e+08
Significant digits lost ≈ 8
Solution x = [0.0005 0.0005 0.1   ]
Residual ||Kx - f|| = 0.00e+00

Diagnosis: The upper-left 2x2 block has nearly identical rows
(rows differ by only 1 N/m out of 1e6), making the system near-singular.
The solution in the first two DOFs is unreliable.
```

출력은 배포 노트북에 실린 출력과 같다. $`K`$는 대칭이므로 2-노름 조건수는 고유값의 절댓값의 최대와 최소의 비이다. 왼쪽 위 $`2 \times 2`$ 블록의 고유값은 $`(1, 1)`$ 방향의 $`2 \times 10^6 - 1`$과 $`(1, -1)`$ 방향의 $`1`$이고, 셋째 자유도의 고유값은 $`0.01`$이므로 $`\kappa_2 = (2 \times 10^6 - 1)/0.01 \approx 2.0 \times 10^8`$이며 $`\log_{10}\kappa_2 \approx 8.3`$에서 8자리를 얻는다. 해는 $`x_1 = x_2 = 1000/(2 \times 10^6 - 1) \approx 5.0 \times 10^{-4}`$ m, $`x_3 = 0.001/0.01 = 0.1`$ m이다.

진단을 구체적으로 확인하기 위해 $`f_2`$를 0.001 N(상대적으로 $`10^{-6}`$)만 바꾸어 풀면 해는 $`[5.0 \times 10^{-10}, 1.0 \times 10^{-3}, 0.1]`$이 된다. 우변의 백만분의 일 변화에 $`x_1`$과 $`x_2`$가 100% 가까이 바뀐다. 두 식을 더하고 빼면 그 이유가 드러난다. $`s = x_1 + x_2`$는 강성 $`2 \times 10^6 - 1`$로 $`(2 \times 10^6 - 1)s = f_1 + f_2`$에서 정해지지만, $`d = x_1 - x_2`$는 강성 1 N/m뿐인 $`d = f_1 - f_2`$에서 정해지므로, $`f_1`$과 $`f_2`$의 작은 오차가 $`d`$에 그대로 실린다.

해결책은 다음과 같이 정리된다.

- **모델과 데이터 점검:** 두 행의 강성 차이 1 N/m가 실제 구조를 반영하는지, 단위나 입력 오류가 아닌지 먼저 확인한다. 두 자유도가 사실상 강체로 묶여 있다면 하나의 자유도로 합쳐 모델을 다시 세운다.
- **변수 변환:** $`s`$와 $`d`$를 미지수로 쓰면 각각 조건이 좋은 스칼라 식이 된다. 다만 $`d`$가 $`f_1 - f_2`$에 민감한 것은 문제 자체의 성질이므로, $`d`$가 필요하면 하중의 차를 그만큼 정밀하게 알아야 한다.
- **스케일링:** 셋째 식에 $`10^8`$을 곱해 크기를 맞추면 조건수는 블록의 값인 약 $`2 \times 10^6`$으로 줄어든다. 이는 셋째 자유도와의 크기 차이에서 온 부분만 없애며, 블록 자체의 악조건은 남는다.

> **참고:** 조건수 $`2 \times 10^8`$ 가운데 100배는 서로 연결되지 않은 셋째 자유도의 작은 강성 0.01에서 온다. 셋째 자유도의 해 $`x_3 = 0.1`$은 독립된 스칼라 식에서 나오므로 정확하며, 실제로 믿을 수 없는 것은 노트북의 진단대로 처음 두 자유도, 그중에서도 차 $`x_1 - x_2`$이다.

## 요약

| 개념 | 핵심 요약 |
|:-----|:-----|
| Doolittle 알고리즘 | 단계마다 $`U`$의 행을 먼저, $`L`$의 열을 나중에 구하며, 공식의 합은 이미 구한 성분의 내적으로 계산한다. |
| 피봇팅과 비교 | 각 단계의 피봇이 이미 열에서 가장 크면 부분 피봇팅도 행을 바꾸지 않으므로 피봇팅 없는 Doolittle 분해와 SciPy의 분해가 같아진다. |
| 전진 대입과 후진 대입 | $`L\mathbf{d} = P^T\mathbf{b}`$를 위에서부터, $`U\mathbf{x} = \mathbf{d}`$를 아래에서부터 풀며, 대각 성분이 1이 아닌 삼각 행렬은 대각 성분으로 나누어야 한다. |
| 다중 우변 | `lu_factor`로 한 번 분해하고 `lu_solve`로 우변마다 $`O(n^2)`$에 풀며, 선형 시스템이므로 해는 중첩 원리를 만족한다. |
| Cholesky 분해를 이용한 풀이 | $`A = LL^T`$이면 두 삼각 시스템을 풀지만, Cholesky 인수의 대각 성분은 1이 아니므로 단위 대각을 가정한 전진 대입을 쓰면 틀린 해가 나온다. |
| LU 분해를 이용한 역행렬 | 한 번 분해한 뒤 단위 행렬의 각 열을 우변으로 풀어 역행렬의 열을 얻으며, 시스템을 풀 때는 역행렬을 만들지 않는 편이 낫다. |
| 조건수 진단 | $`\kappa(A) \approx 10^k`$이면 약 $`k`$자리를 잃으며, 거의 같은 두 행은 두 미지수의 차를 거의 정할 수 없게 만든다. |

## 점검 문제

1. **빈 슬라이스:** 문제 1에서 $`k = 0`$일 때 `L[k, :k] @ U[:k, j]`는 어떤 값이 되며, 그것이 왜 공식과 맞는가?

   <details>
   <summary>정답</summary>

   두 슬라이스가 길이 0인 배열이 되어 내적이 0이다. 공식의 합 $`\sum_{m=0}^{-1}`$도 빈 합이어서 0이므로 $`u_{0j} = a_{0j}`$가 되어 일치한다.

   </details>

2. **P의 전치:** 문제 2의 `lu_solve`에서 우변을 `P @ b`가 아니라 `P.T @ b`로 바꾸는 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   `sc.linalg.lu`는 $`A = PLU`$를 만족하는 $`P`$를 돌려준다. 따라서 $`LU\mathbf{x} = P^{-1}\mathbf{b}`$이고, 치환 행렬은 직교 행렬이어서 $`P^{-1} = P^T`$이므로 우변은 $`P^T\mathbf{b}`$이다.

   </details>

3. **Cholesky 풀이의 오류:** 문제 4의 결과가 틀린 원인과 고치는 방법을 설명하라.

   <details>
   <summary>정답</summary>

   `forward_sub`는 단위 하삼각 행렬을 가정해 대각 성분으로 나누지 않는데, Cholesky 인수 $`L`$의 대각 성분은 $`141.42, 122.47, 115.47, 50`$이다. 전진 대입에서 `L[i, i]`로 나누거나 `sc.linalg.solve_triangular(L, b, lower=True)`를 쓰면 정확한 변위 $`[150, 300, 450, 550]`$ mm가 나온다.

   </details>

4. **분해의 위치:** 문제 5에서 `sc.linalg.lu_factor(A)`를 반복문 안에 넣으면 결과와 비용이 어떻게 달라지는가?

   <details>
   <summary>정답</summary>

   결과는 같지만, 열마다 $`O(n^3)`$의 분해를 반복하므로 전체 비용이 $`O(n^3) + nO(n^2)`$에서 $`nO(n^3) = O(n^4)`$로 늘어난다.

   </details>

5. **조건수의 구성:** 문제 6의 조건수 $`2 \times 10^8`$은 어떤 두 값의 비이며, 셋째 식을 스케일링하면 왜 $`2 \times 10^6`$으로 줄어드는가?

   <details>
   <summary>정답</summary>

   대칭 행렬의 2-노름 조건수는 고유값 절댓값의 최대와 최소의 비이며, 여기서는 블록의 $`2 \times 10^6 - 1`$과 셋째 자유도의 $`0.01`$의 비이다. 셋째 식에 $`10^8`$을 곱하면 그 고유값이 $`10^6`$이 되어 최소 고유값이 블록의 1로 바뀌므로 조건수는 약 $`2 \times 10^6`$이 된다.

   </details>
