## 3. 문제: 복합 사다리꼴 법칙

### 3.1 풀이 방법

노드를 $`x_i = a + ih`$ $`(i = 0, 1, \ldots, n)`$, 함숫값을 $`f_i = f(x_i)`$라 하자. 각 소구간 $`[x_{i-1}, x_i]`$에 사다리꼴 법칙을 적용해 더하면, 안쪽 노드는 이웃한 두 소구간에서 한 번씩 쓰여 두 번 더해지고 양 끝 노드는 한 번만 더해진다.

$$
I \approx \frac{h}{2}\left(f_0 + 2\sum_{i=1}^{n-1} f_i + f_n\right)
$$

`y = func(x)`는 길이 $`n + 1`$인 배열 $`(f_0, f_1, \ldots, f_n)`$이므로 공식의 각 부분은 다음 배열 연산에 대응한다.

| 공식의 항 | 배열 연산 |
|:-----|:-----|
| $`f_0`$ | `y[0]` |
| $`f_n`$ | `y[-1]` |
| $`\sum_{i=1}^{n-1} f_i`$ | `np.sum(y[1:-1])` |

*표 2. 복합 사다리꼴 법칙의 항과 배열 연산의 대응*

$`n = 1`$이면 `y[1:-1]`은 빈 배열이고 `np.sum`은 0을 돌려주므로, 식은 $`\frac{h}{2}(f_0 + f_1)`$이 되어 단일 구간 사다리꼴 법칙과 같아진다. 복합 사다리꼴 법칙의 유도는 [19장 강의 노트](../../Lecture-Notes/Ch19_Numerical-Integration-Formulas/Concepts_Lecture.ko.md)의 5.2절에서 다룬다.

### 3.2 작성한 코드

```python
    I = h/2 * (y[0] + 2*np.sum(y[1:-1]) + y[-1])
```

### 3.3 실행 결과와 검증

```text
Single-segment Trapezoidal: I = 0.172800,  error = 89.47%

Composite Trapezoidal Rule:
     n             I     error %
     1    0.17280000     89.4668
     2    1.06880000     34.8505
     4    1.48480000      9.4928
     8    1.60080000      2.4220
    16    1.63055000      0.6085
    32    1.63803438      0.1523
    64    1.63990840      0.0381
```

출력은 배포 노트북에 실린 출력과 같다. 결과는 다음 세 가지로 확인한다.

**손 계산.** $`f(0) = 0.2`$, $`f(0.4) = 2.456`$, $`f(0.8) = 0.232`$이다. $`n = 1`$이면 $`h = 0.8`$이므로 $`I = 0.4 \times (0.2 + 0.232) = 0.1728`$이고, 단일 구간 사다리꼴 법칙의 값과 같다. $`n = 2`$이면 $`h = 0.4`$이므로 $`I = 0.2 \times (0.2 + 2 \times 2.456 + 0.232) = 0.2 \times 5.344 = 1.0688`$이다. 두 값 모두 출력과 일치한다.

**오차의 수렴 비율.** 오차 $`E = I_{\text{exact}} - I`$와, $`n`$을 두 배로 늘렸을 때의 오차 비율은 다음과 같다.

| $`n`$ | $`h`$ | $`I`$ | 오차 $`E`$ | 비율 | $`4h^2`$ |
|:-----|:-----|:-----|:-----|:-----|:-----|
| 1 | 0.8 | 0.1728000000 | 1.467733e+00 | | 2.560000e+00 |
| 2 | 0.4 | 1.0688000000 | 5.717333e-01 | 2.5672 | 6.400000e-01 |
| 4 | 0.2 | 1.4848000000 | 1.557333e-01 | 3.6712 | 1.600000e-01 |
| 8 | 0.1 | 1.6008000000 | 3.973333e-02 | 3.9195 | 4.000000e-02 |
| 16 | 0.05 | 1.6305500000 | 9.983333e-03 | 3.9800 | 1.000000e-02 |
| 32 | 0.025 | 1.6380343750 | 2.498958e-03 | 3.9950 | 2.500000e-03 |
| 64 | 0.0125 | 1.6399083984 | 6.249349e-04 | 3.9987 | 6.250000e-04 |

*표 3. 소구간 수에 따른 복합 사다리꼴 법칙의 오차와 오차 비율*

비율은 4에 다가가며, 이는 오차가 $`h^2`$에 비례한다는 이론과 맞는다. 노트북의 수렴 연구 셀이 $`n = 2`$부터 $`256`$까지의 오차로 구한 로그-로그 기울기도 $`-1.98`$로 $`-2`$에 가깝다.

**오차 추정식과의 비교.** 19장 강의 노트의 오차 추정식은 $`E_a \approx -\frac{b-a}{12}\,\overline{f''}\,h^2`$이고, 평균 2계도함수는 $`\overline{f''} = \frac{f'(b) - f'(a)}{b - a}`$이다. $`f'(x) = 25 - 400x + 2025x^2 - 3600x^3 + 2000x^4`$에서 $`f'(0) = 25`$, $`f'(0.8) = -23`$이므로 $`\overline{f''} = -48/0.8 = -60`$이고, $`E_a \approx \frac{0.8}{12} \times 60 \times h^2 = 4h^2`$이다. 표 3에서 $`n`$이 커질수록 실제 오차는 $`4h^2`$에 가까워지며, $`n = 64`$에서는 유효 숫자 4자리까지 같다.

> **참고:** 표 3의 실제 오차는 모든 $`n`$에서 반올림 오차 범위 안에서 $`4h^2 - \frac{8}{3}h^4`$과 일치한다. [20장 강의 노트](../../Lecture-Notes/Ch20_Numerical-Integration-of-Functions/Concepts_Lecture.ko.md)의 2.2절이 제시하는 오차 전개 $`I = I_h + Ch^2 + Dh^4 + O(h^6)`$에서 $`C = 4`$, $`D = -8/3`$이고 $`h^6`$ 이상의 항이 나타나지 않는 경우에 해당한다. 비율이 4보다 작은 쪽에서 4에 다가가는 것은 부호가 반대인 $`h^4`$ 항 때문이며, $`n`$이 작을 때 이 항의 비중이 크다.

### 3.4 뒤의 셀에서 쓰인 결과

이 함수는 노트북 곳곳에서 다시 쓰인다. 노트북 4절의 함수 `romberg`는 Romberg 표의 첫 열을 $`n = 2^k`$개의 소구간에 대한 `composite_trap`의 값으로 채운 뒤 Richardson 외삽법을 적용한다. 완성한 노트북의 출력은 다음과 같다.

```text
Romberg Table:
Level k   n=2^k      R[k,0]          R[k,1]          R[k,2]          R[k,3]    
----------------------------------------------------------------------------------
      0       1    0.1728000000                                                
      1       2    1.0688000000    1.3674666667                                
      2       4    1.4848000000    1.6234666667    1.6405333333                
      3       8    1.6008000000    1.6394666667    1.6405333333    1.6405333333

Best estimate R[3,3] = 1.640533333333
Exact                  = 1.640533333333
Error                  = 2.89e-15
```

- **첫 열:** `R[k,0]`은 3.3절의 $`n = 1, 2, 4, 8`$ 값과 같다. 빈칸이 틀렸다면 Romberg 표 전체가 틀렸을 것이다.
- **둘째 열:** `R[1,1]` $`= (4 \times 1.0688 - 0.1728)/3 = 1.3674667`$이며, 이는 노트북 3절의 소구간 2개짜리 복합 Simpson 1/3 법칙 값 1.36746667과 같다. `R[2,1]`과 `R[3,1]`도 소구간 4개와 8개의 Simpson 1/3 법칙 값과 같아, 사다리꼴 값 두 개를 외삽하면 Simpson 1/3 법칙이 된다는 사실을 보여 준다.
- **셋째 열:** `R[2,2]`부터 정확한 값 1.6405333333이 나온다. 3.3절의 참고 상자처럼 이 함수의 사다리꼴 오차가 $`h^2`$ 항과 $`h^4`$ 항뿐이므로, 두 번의 외삽으로 두 항이 모두 제거되기 때문이다.

이 밖에도 함수는 노트북 2절의 수렴 그래프, 3절의 Simpson 법칙 비교, 5절의 Gauss-Legendre 구적법과의 비교, 8절의 열유속, 호의 길이, 추력 적분 응용에서 기준 방법으로 쓰인다.

## 점검 문제

1. **안쪽 노드의 계수:** 복합 사다리꼴 법칙에서 안쪽 노드의 함숫값에 2가 곱해지는 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   안쪽 노드 $`x_i`$ $`(1 \le i \le n-1)`$는 왼쪽 소구간 $`[x_{i-1}, x_i]`$의 오른쪽 끝이자 오른쪽 소구간 $`[x_i, x_{i+1}]`$의 왼쪽 끝이어서, 두 사다리꼴에 한 번씩 쓰인다. 양 끝 노드는 소구간 하나에만 속하므로 한 번만 더해진다.

   </details>

2. **소구간이 하나일 때:** 작성한 코드에서 $`n = 1`$이면 어떤 계산이 일어나며, 결과는 무엇과 같은가?

   <details>
   <summary>정답</summary>

   `x`는 $`[a, b]`$의 두 점이고 `y[1:-1]`은 빈 배열이어서 `np.sum(y[1:-1])`은 0이다. 따라서 $`I = \frac{h}{2}(f(a) + f(b))`$이고 $`h = b - a`$이므로 단일 구간 사다리꼴 법칙과 같다. 기준 함수에서는 0.1728이다.

   </details>

3. **오차 비율:** 오차가 $`h^2`$에 비례하면 $`n`$을 두 배로 늘릴 때 오차는 몇 분의 1이 되는가? 표 3에서 $`n = 1`$에서 2로 늘릴 때의 비율이 2.57에 그친 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   $`h`$가 절반이 되므로 오차는 $`(1/2)^2 = 1/4`$이 되어 비율은 4이다. $`n`$이 작아 $`h`$가 크면 오차 전개에서 $`h^4`$ 항의 비중이 커서, 주도 항 $`h^2`$만으로 예측한 비율과 차이가 난다. 기준 함수에서는 $`h^4`$ 항의 부호가 반대여서 비율이 4보다 작다.

   </details>

4. **오차 추정식:** 오차 추정식 $`E_a \approx -\frac{b-a}{12}\overline{f''}h^2`$이 $`n = 1`$에서 2.56을 주는데 실제 오차는 1.468이다. 추정이 $`n`$이 클수록 정확해지는 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   추정식은 오차 전개의 주도 항 $`h^2`$만 남긴 근사이다. $`h`$가 크면 무시한 $`h^4`$ 항($`-\frac{8}{3}h^4 \approx -1.09`$)이 크지만, $`h`$가 작아지면 이 항이 $`h^2`$ 항보다 훨씬 빠르게 작아지므로 추정이 실제 오차에 가까워진다.

   </details>

5. **Romberg 표의 첫 열:** Romberg 적분의 첫 외삽 `R[1,1]`을 사다리꼴 값 `R[0,0]`과 `R[1,0]`으로 쓰고, 기준 함수에서 그 값을 구하라.

   <details>
   <summary>정답</summary>

   `R[1,1]` $`= (4R_{1,0} - R_{0,0})/3 = (4 \times 1.0688 - 0.1728)/3 = 1.3674667`$이다. 이 값은 소구간 2개짜리 복합 Simpson 1/3 법칙의 값과 같다.

   </details>
